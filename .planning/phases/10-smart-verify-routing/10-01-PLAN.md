  <behavior>
    New types in `src/core/types.ts`:

    ```typescript
    export type ProjectType = 'web' | 'cli' | 'file-content';
    export type VerifyStrategy = 'auto' | 'browser' | 'file' | 'cli';
    ```

    New `src/core/verify-routing.ts` with two exported functions:

    1. `detectProjectType(projectDir: string): Promise<ProjectType>`
       Heuristic-based detection, checked in order (first match wins):

       **Web signals (returns 'web'):**
       - package.json has `scripts.dev` containing any of: `vite`, `next`, `remix`, `nuxt`, `astro`, `webpack-dev-server`, `react-scripts start`
       - package.json has `scripts.start` containing any of: `node server`, `express`, `fastify`, `http-server`
       - package.json has dependencies containing: `next`, `remix`, `nuxt`, `astro`, `vite` (not devDependencies-only)
       - Any files matching glob patterns: `src/**/*.{jsx,tsx}`, `app/**/*.{jsx,tsx}`, `pages/**/*.{jsx,tsx}` (route-like files)
       - package.json contains strings matching: `localhost`, `:3000`, `:8080`, `:5173`

       **CLI signals (returns 'cli'):**
       - package.json has `bin` field
       - package.json has `scripts.build` but NO web signals matched
       - Has files in `src/` or `dist/` but no JSX/TSX files

       **File-content default (returns 'file-content'):**
       - No package.json exists
       - package.json exists but no web or CLI signals match
       - Project contains only markdown, JSON, YAML, config files

    2. `resolveVerifyStrategy(explicit: VerifyStrategy, projectDir: string): Promise<{ strategy: ProjectType; reason: string }>`
       - If explicit is 'browser', 'file', or 'cli' → return the corresponding ProjectType directly with reason "explicit --strategy flag"
       - If explicit is 'auto' → call detectProjectType and return with reason describing what signal matched

    Test cases:
    - Web: package.json with `"dev": "vite"` → 'web'
    - Web: package.json with `"dev": "next dev"` → 'web'
    - Web: package.json with `"start": "node server.js"` and `dependencies: { "express": "..." }` → 'web'
    - Web: project with `src/app/page.tsx` file → 'web'
    - CLI: package.json with `"bin": { "pilot": "./dist/index.js" }` and no web signals → 'cli'
    - CLI: package.json with build script, no server, no JSX → 'cli'
    - File-content: no package.json → 'file-content'
    - File-content: only markdown files → 'file-content'
    - File-content: package.json with no bin, no dev script, no web deps → 'file-content'
    - resolveVerifyStrategy('browser', dir) → { strategy: 'web', reason: 'explicit --strategy flag' }
    - resolveVerifyStrategy('auto', webDir) → { strategy: 'web', reason: '...' }
    - resolveVerifyStrategy('auto', cliDir) → { strategy: 'cli', reason: '...' }
  </behavior>
