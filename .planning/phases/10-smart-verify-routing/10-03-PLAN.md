<task type="auto">
  <name>Task 2: Integrate smart verify routing into lifecycle runner</name>
  <files>src/core/lifecycle.ts</files>
  <action>
    Update the `runPhaseCycle` function's `case 'needs-verify':` block (currently lines 344-361) to route through smart verification for non-web projects.

    1. Add imports at top of lifecycle.ts:
       - `detectProjectType` from `./verify-routing.js`
       - `runFileContentVerification`, `runCliVerification` from `./verify-strategies.js`

    2. In the `case 'needs-verify':` block, BEFORE spawning gsd-verify-auto:
       a. Detect project type: `const projectType = await detectProjectType(projectDir);`
       b. Log: `process.stderr.write(`[lifecycle] Phase ${phase}: verify strategy=${projectType}\n`);`
       c. If projectType is 'file-content' or 'cli':
          - Run the appropriate verification function directly (no AI agent spawn)
          - `const result = projectType === 'cli' ? await runCliVerification(projectDir, phase) : await runFileContentVerification(projectDir, phase);`
          - If `result.passed`:
            - Write STATE to 'verified'
            - Log: `[lifecycle] Phase ${phase}: ${projectType} verification passed (${result.passedChecks}/${result.totalChecks} checks)`
          - If `!result.passed`:
            - Log issues: `[lifecycle] Phase ${phase}: ${projectType} verification found issues: ${result.issues.join(', ')}`
            - Write STATE to 'needs-gaps' (same as browser UAT failure)
            - Note: The UAT file is not created by pilot's verification. The phase state detection will pick up 'needs-gaps' from the STATE file.
          - `break;` (skip the gsd-verify-auto spawn)
       d. If projectType is 'web':
          - Fall through to existing gsd-verify-auto spawn logic (unchanged)

    **IMPORTANT:** Do NOT change the existing web project flow. The gsd-verify-auto spawn + exit code handling + state checking stays exactly as-is for web projects.

    **IMPORTANT:** The verification result for file/cli strategies needs to be written as a UAT-style file so gap closure can find failures. Write a simple UAT file to the phase directory:
    ```
    # Verification Results (${projectType} strategy)
    
    result: ${result.passed ? 'pass' : 'fail'}
    failed: ${result.failedChecks}
    
    ## Issues
    ${result.issues.map(i => `- ${i}`).join('\n')}
    ```
    Write to: `${phaseDir}/${padded}-UAT.md` (same location gsd-verify-auto would write).
  </action>
