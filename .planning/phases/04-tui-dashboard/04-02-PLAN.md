**Update `src/commands/tui.ts`** — replace the stub with a real implementation:

```typescript
interface TuiOpts {
  interval?: number;
  json?: boolean;
}
```

Implementation of `tuiCommand(opts: TuiOpts)`:

1. If `opts.json` → exit 1 with error: "TUI does not support --json mode"

2. **Lazy import ink and App:**
```typescript
const [{ render }, { App }] = await Promise.all([
  import('ink'),
  import('../tui/App.js'),
]);
```
This is the critical pattern — `import('ink')` is dynamic, not static. It ensures ink+react are NOT loaded for any other command.

3. Get interval from opts (default 3 seconds):
```typescript
const interval = opts.interval ?? 3;
```

4. Render with fullscreen:
```typescript
const { waitUntilExit } = render(<App interval={interval} />, {
  exitOnCtrlC: true,
});
await waitUntilExit();
```

Note: This file MUST be `.ts` (not `.tsx`) but it uses JSX in the render call. Two options:
- Option A: Make it `.tsx` — but then the import in index.ts needs updating. Check if index.ts imports it already.
- Option B: Use `React.createElement` instead of JSX.

**Use Option B** — keep the file as `.ts` to avoid any changes to index.ts import paths:
```typescript
const { createElement } = await import('react');
const { render } = await import('ink');
const { App } = await import('../tui/App.js');

const { waitUntilExit } = render(
  createElement(App, { interval }),
  { exitOnCtrlC: true }
);
await waitUntilExit();
```

5. Export `tuiCommand` as named export.

**Update `package.json`**: Move ink, react, @types/react from `optionalDependencies` to their proper locations:
- `ink` → `dependencies`
- `react` → `dependencies`  
- `@types/react` → `devDependencies`

- Remove the `optionalDependencies` section entirely

This matches the spec: "Phase 3 moves them to dependencies."
