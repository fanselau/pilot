  <files>src/commands/models.ts</files>
  <action>
  Create `src/commands/models.ts` with these command handlers:

  **1. `modelsShowCommand(opts: { json?: boolean; providerMode?: string })`** (default action for `pilot models` and `pilot models show [mode]`)
  - If providerMode specified, show just that mode. Otherwise show the active mode from config defaults.
  - Get all entries via `getAllEntriesForMode(mode)` from model-store
  - Group entries by agent_or_scope
  - For each entry, check `isCustomized()` to detect user modifications
  - Display as a table:
    ```
    Provider Mode: claude-only (built-in)

    Agent/Scope          quality                           balanced                          budget
    ─────────────────────────────────────────────────────────────────────────────────────────────────
    gsd-planner          anthropic/claude-opus-4-6         anthropic/claude-opus-4-6         anthropic/claude-sonnet-4-6
    gsd-executor         anthropic/claude-opus-4-6         anthropic/claude-sonnet-4-6 *     anthropic/claude-sonnet-4-6
    ```
    - `*` suffix on customized entries (entries that differ from AGENT_MODELS defaults)
    - Use yellow color for customized entries
    - Scope entries (_top:phase, _top:quick, _top:judge) displayed in a separate "Scopes" section
  - `--json` mode: output full entries array as JSON
  - If no entries found for the mode, show error: "Provider mode '{mode}' not found. Run `pilot models` to see available modes."
  - When no mode specified and showing default, also list available provider modes at the bottom:
    ```
    Available provider modes: claude-only, openai-only, hybrid
    ```

  **2. `modelsEditCommand(opts: { json?: boolean })`** (`pilot models edit`)
  - Interactive flow using Node.js readline (same pattern as init.ts):
    a. List and prompt to select a provider mode (numbered list)
    b. List and prompt to select an agent/scope (numbered list)
    c. Prompt for new model string (freeform text, format: `provider/model-id`)
    d. Prompt for variant (freeform text, empty for none)
    e. Show before/after diff:
       ```
       Before: anthropic/claude-sonnet-4-6
       After:  anthropic/claude-opus-4-6

       Apply? (y/n):
       ```
    f. On confirm, call `setModelEntry()` from model-store
    g. On reject, print "Cancelled." and exit
  - Must handle Ctrl+C gracefully (close readline, exit)
  - Profile selection: After selecting agent/scope, prompt which profile(s) to change: "Which profile? (1) quality (2) balanced (3) budget (4) all:"

  **3. `modelsResetCommand(providerMode?: string, opts?: { json?: boolean })`** (`pilot models reset [mode]`)
  - If providerMode specified: call `resetProviderMode(mode)` from model-store
  - If no mode specified: call `resetAllToDefaults()` from model-store
  - Print confirmation: "Reset {mode} to built-in defaults." or "Reset all model assignments to built-in defaults."
  - `--json` mode: output `{ reset: true, mode: string | 'all' }`

  Use these imports:
  - readline from 'node:readline' (for interactive edit)
  - model-store functions from '../core/model-store.js'
  - getConfigFileDefaults from '../core/config.js' (for default providerMode)
  - output utilities from '../util/output.js'
  - color utilities from '../util/colors.js'

<task type="auto">
  <name>Task 2: Wire models commands into CLI entry point</name>
  <files>src/index.ts</files>
  <action>
  In `src/index.ts`, add the `pilot models` command group following the same nested subcommand pattern as `config` and `skills`.

  ```typescript
  // ── Models command group ────────────────────────────────────────────────
  const modelsCmd = program.command('models').description('View and edit model assignments');

  // Default action: pilot models (shows current mapping)
  modelsCmd.action(async (opts: Record<string, unknown>) => {
    const { modelsShowCommand } = await import('./commands/models.js');
    await modelsShowCommand({ ...program.opts(), ...opts });
  });

  // pilot models show [mode]
  modelsCmd
    .command('show [mode]')
    .description('Show model mapping for a provider mode')
    .action(async (mode: string | undefined, opts: Record<string, unknown>) => {
      const { modelsShowCommand } = await import('./commands/models.js');
      await modelsShowCommand({ ...program.opts(), ...opts, providerMode: mode });
    });

  // pilot models edit
  modelsCmd
    .command('edit')
    .description('Interactively edit model assignments')
    .action(async (opts: Record<string, unknown>) => {
      const { modelsEditCommand } = await import('./commands/models.js');
      await modelsEditCommand({ ...program.opts(), ...opts });
    });

  // pilot models reset [mode]
  modelsCmd
    .command('reset [mode]')
    .description('Reset model assignments to built-in defaults')
    .action(async (mode: string | undefined, opts: Record<string, unknown>) => {
      const { modelsResetCommand } = await import('./commands/models.js');
      await modelsResetCommand(mode, { ...program.opts(), ...opts });
    });
  ```

  Place this block near the other command groups (after `skills` or `config`).
  </action>
