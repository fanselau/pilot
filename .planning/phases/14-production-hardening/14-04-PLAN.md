2. **DaemonStuckAssessment type** (add to types.ts):
   ```typescript
   export interface DaemonStuckAssessment {
     score: number;           // 0-100+
     verdict: 'healthy' | 'suspect' | 'stuck';
     signals: StuckSignal[];
     isFlaky: boolean;        // <5 messages and quick exit
   }
   ```

3. **Signals to check (NO CPU sampling — too slow for 60s cycle):**

   a. **Log staleness (max 50 points):** Read log file mtime.
      - Log stale > 15min AND runtime > 15min → 30 points
      - Log stale > 5min AND runtime > 10min → 20 points
   
   b. **Process state (max 80 points):** Read `/proc/${pid}/status` for State field, `/proc/${pid}/wchan`.
      - State 'T' (stopped) → 50 points
      - State 'Z' (zombie) → 80 points
      - wchan matches `read|wait|poll` AND runtime > 10min → 30 points
   
   c. **Memory (max 20 points):** Read `/proc/${pid}/status` for VmRSS.
      - RSS > 1024MB → 10 points
      - System free mem < 500MB → 10 points

   d. **No output at all (max 40 points):** If log file is empty or doesn't exist:
      - runtime > 5min AND log size 0 → 40 points

   Same threshold: score ≥ 70 → stuck, 40-69 → suspect, < 40 → healthy.

4. **Skip synthetic PIDs:** The function should only be called for real PIDs (> 0). Lifecycle mode synthetic PIDs (< 0) are handled differently.

5. **Wrap all /proc reads in try/catch** — process may have just died. Return healthy if unreadable.

6. Export `computeDaemonStuckScore` from stuck.ts.

   ```typescript
   private async checkStuckJobs(): Promise<void> {
     for (const [pid, job] of this.state.activeJobs) {
       // Skip synthetic PIDs (lifecycle modes — managed differently)
       if (pid < 0) continue;
       
       const runtimeSeconds = Math.round((Date.now() - job.startTime) / 1000);
       
       try {
         const assessment = await computeDaemonStuckScore(
           pid, job.title, job.logFile, runtimeSeconds,
         );
         
         if (assessment.verdict === 'stuck') {
           this.emit('error', 
             `Job ${job.title} is stuck (score ${assessment.score}): ` +
             assessment.signals.map(s => s.detail).join(', ')
           );
           
           // Kill the process tree
           try { process.kill(-pid, 'SIGTERM'); } catch { /* group may not exist */ }
           await sleep(5000);
           if (isProcessAlive(pid)) {
             await killProcessTree(pid);
           }
           
           // Set exit code to trigger reap → handleJobCompletion handles retry
           this.state.exitCodes.set(pid, -1);
         }
       } catch {
         // Stuck check failure must not crash daemon
       }
     }
   }
   ```
