<task type="auto">
  <name>Task 1: Setup and update commands</name>
  <files>src/commands/setup.ts, src/commands/update.ts</files>
  <action>
**src/commands/setup.ts** — `export async function setupCommand(dir: string, opts)`

1. Validate that `getConfig().gsdDir` exists using `fs.access()`. If not → `process.stderr.write('Error: pilot-gsd not found at ...\n'); process.exit(1);`
2. Call `setupProject(dir)` from core/setup.ts — this returns `SetupResult { created, skipped, errors }`
3. **JSON mode:** `outputJson({ dir: path.resolve(dir), ...result })`
4. **Human mode:** Match spec format:
   - For each `result.created`: `outputHuman(green('✓') + ' Created ' + item)`
   - For each `result.skipped`: `outputHuman(dim('○') + ' Skipped ' + item)`
   - For each `result.errors`: `outputHuman(red('✗') + ' Error: ' + item)`
   - Footer: `outputHuman('Setup complete: ' + path.resolve(dir))`
   - If `result.errors.length > 0`: exit 1 after reporting

**src/commands/update.ts** — `export async function updateCommand(opts)`

1. Get config, check `config.gsdDir` exists. If not → exit 1 with error.
2. `outputHuman('Updating pilot-gsd...')`
3. Run `execa('git', ['pull'], { cwd: config.gsdDir })` — capture stdout
4. `outputHuman(result.stdout.trim())`
5. `outputHuman(green('✓') + ' pilot-gsd is current')`
6. **JSON mode:** `outputJson({ gsd_dir: config.gsdDir, git_output: result.stdout.trim() })`
7. On execa error → exit 1 with `Error: git pull failed: ${error.message}`
  </action>
  <verify>
`tsc --noEmit` passes for both files.
`npx tsx src/index.ts setup --help` — shows setup command help with `<dir>` argument.
`npx tsx src/index.ts update --json 2>/dev/null` — outputs JSON or exits 1.
  </verify>
  <done>
`pilot setup <dir>` delegates to core/setup.ts and renders results with ✓/○/✗ icons. `pilot update` runs git pull in pilot-gsd dir. Both handle missing pilot-gsd with exit 1. Both support --json.

- `vi.mock('../../src/core/config.js', () => ({ getConfig: vi.fn(() => ({ queueFile: '/tmp/QUEUE.md', logDir: '/tmp', stuckThreshold: 90, projectDir: '/tmp/projects', gsdDir: '/tmp/gsd', noColor: true })) }))`

**Test cases:**
1. `status --json outputs valid PilotStatusJson shape` — Set mocks to return known data. Import statusCommand, call with `{ json: true }`. Capture stdout (spy on `process.stdout.write`). Parse JSON output. Verify: has `timestamp` (string), `summary` with running/stuck/suspect/queued/completed fields (numbers), `sessions` with running/stuck/suspect arrays, `queue` array, `completed` array, `runner` object.
2. `status with no sessions shows zeros` — Mock listSessions→[], scanPidFiles→[], parseQueueFile→[]. Call with json mode. Verify summary has all zeros.
3. `status cross-references sessions with PIDs` — Mock listSessions with 2 sessions, scanPidFiles with 1 matching PID. Verify the matched session appears in `sessions.running`, the unmatched in `completed`.

Before each test: `vi.clearAllMocks()`. After each: restore stdout spy.

Use `setJsonMode(true)` from util/output.ts before calling commands in tests so they output JSON (easier to assert against).

**test/commands/queue.test.ts:**

Mock core/config.js and core/queue-parser.js.

**Test cases:**
1. `queue --json outputs entries with correct fields` — Mock parseQueueFile with fixture data (pending, running, done, failed entries). Verify JSON output has `queue` array where each item has: status, project, mode, args, description, line_num.
2. `queue exits 1 when file not found` — Mock parseQueueFile to throw ENOENT error. Spy on `process.exit`. Verify exit(1) called and stderr contains error message.
3. `queue groups entries correctly` — Mock with mixed statuses. Call with json mode. Verify entries are present (JSON doesn't reorder, but all entries are included).
4. `queue active_count is running + pending` — Verify the `active_count` field in JSON output equals running + pending count.

**Pattern for capturing command output:**
```typescript
let output = '';
const writeSpy = vi.spyOn(process.stdout, 'write').mockImplementation((chunk: string | Uint8Array) => {
  output += typeof chunk === 'string' ? chunk : new TextDecoder().decode(chunk);
  return true;
});
// ... call command ...
writeSpy.mockRestore();
const parsed = JSON.parse(output);
```

**Pattern for testing exit codes:**
```typescript
const exitSpy = vi.spyOn(process, 'exit').mockImplementation((() => { throw new Error('exit'); }) as never);
// ... expect(() => command()).rejects.toThrow('exit') or try/catch
exitSpy.mockRestore();
```

Mock `process.exit` carefully — it must throw so the command stops executing. Use `(() => { throw new Error('process.exit'); }) as never` cast.
