  <action>
    1. Install `@tanstack/react-virtual` in the web subproject:
       ```bash
       cd web && pnpm add @tanstack/react-virtual
       ```

    2. Update `web/src/components/step-content-pane.tsx` to use virtualization:
       - Import `{ useVirtualizer }` from `@tanstack/react-virtual`
       - Flatten the selected step's items into a flat array for virtualization
       - Create a scroll container with ref: `const parentRef = useRef<HTMLDivElement>(null)`
       - Set up virtualizer:
         ```typescript
         const virtualizer = useVirtualizer({
           count: items.length,
           getScrollElement: () => parentRef.current,
           estimateSize: () => 40, // estimated row height in px
           overscan: 20,
         })
         ```
       - Render virtual rows:
         ```tsx
         <div ref={parentRef} className="h-full overflow-auto">
           <div style={{ height: `${virtualizer.getTotalSize()}px`, position: 'relative' }}>
             {virtualizer.getVirtualItems().map((virtualRow) => {
               const item = items[virtualRow.index]
               return (
                 <div
                   key={virtualRow.key}
                   style={{
                     position: 'absolute',
                     top: 0,
                     left: 0,
                     width: '100%',
                     transform: `translateY(${virtualRow.start}px)`,
                   }}
                   ref={virtualizer.measureElement}
                   data-index={virtualRow.index}
                 >
                   <TimelineItemRenderer item={item} jobId={jobId} />
                 </div>
               )
             })}
           </div>
         </div>
         ```
       - Only enable virtualization when items count exceeds a threshold (e.g., 200 items). Below that, render normally for simpler DOM.
       - When `autoFollow` is true and data changes, scroll to bottom: `virtualizer.scrollToIndex(items.length - 1, { align: 'end' })`

    3. **Scroll-to-bottom on mount for running jobs:**
       - Use useEffect: when `isActive` (derived from parent) and first render, scroll to bottom
       - When auto-follow is active, scroll on every data change
       - The "Follow" button should call `virtualizer.scrollToIndex(items.length - 1)` and set autoFollow=true

    4. For the left pane timeline (step-timeline-sidebar), do NOT virtualize — it typically has <20 steps and doesn't need it.
  </action>
