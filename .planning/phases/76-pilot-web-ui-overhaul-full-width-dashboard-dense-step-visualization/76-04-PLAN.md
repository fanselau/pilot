<interfaces>
react-resizable-panels API (from Context7 docs):
```tsx
import { Group, Panel, Separator } from "react-resizable-panels";

<Group orientation="horizontal" style={{ height: "100vh" }}>
  <Panel defaultSize="34%" minSize={300}>Left</Panel>
  <Separator />
  <Panel defaultSize="66%">Right</Panel>
</Group>
```
Panel supports: defaultSize, minSize, maxSize, collapsible, collapsedSize, panelRef, onResize.

From src/core/types.ts:
```typescript
export interface StepTimelineGroup {
  stepIndex: number | null;
  command: string;
  status: string;
  sessionId: string | null;
  source: string;
  items: StepTimelineItem[];
}

export interface JobDetailSnapshot {
  job: { id, status, description, project, scope, modelProfile, providerMode,
         currentStep, startedAt, completedAt, createdAt, durationMs,
         verdict, error, observedModels, ... };
  steps: JobStepSummary[];
  rootSessions: SessionSummary[];
  subagents: SessionSummary[];
}
```

The `job.observedModels` field is a `string[]` of actual model identifiers used.
