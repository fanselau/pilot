    Transform the BranchLifecycleBlock from a link-to-drill-in-page into an inline collapsible that shows session activity directly:
    
    1. **Rewrite `branch-lifecycle-block.tsx`**:
       - Replace the `<Link to="/jobs/$jobId/sessions/$sessionId">` wrapper with a `<Collapsible>` from Coss UI
       - The collapsed state shows the current card header: branch identity, status, model badges, duration, token count, preview text
       - The expanded state reveals:
         - `<SessionActivity sessionId={item.sessionId} />` — the full session activity stream
         - Nested child sessions (if any) — recursive BranchLifecycleBlock for each child
       - **Collapse/expand defaults by hierarchy level**:
         - Level 1 (direct children of a step): Collapsed by default if `status === 'done'`, expanded if `status === 'active'`
         - Level 2+ (grandchildren and deeper): Always collapsed by default
         - Rationale: Users want to see active work immediately but can drill into completed branches on demand
       - Add a prop `depth: number` (default 0) to track nesting depth for default behavior and indentation
       - Use `<Collapsible defaultOpen={item.status === 'active' && depth < 2}>` for the default expand behavior
    
    2. **Add collapsible trigger styling**:
       - The header card acts as the trigger: `<CollapsibleTrigger className="w-full text-left cursor-pointer">`
       - Add a chevron icon (▸ collapsed, ▾ expanded) on the left side of the header
       - Add subtle hover state: `hover:bg-accent/30`
       - Active/expanded: slightly different background `bg-accent/10`
    
    3. **Add live polling for inline session activity**:
       - In `session-activity.tsx`, ensure the `useQuery` for session activity has a `refetchInterval`:
         - Active sessions: `refetchInterval: 3000` (same as parent job polling)
         - Done sessions: `refetchInterval: false` (no polling)
       - Pass `isActive` prop to `SessionActivity` component so it knows when to poll
       - Add `isActive?: boolean` prop: `<SessionActivity sessionId={id} isActive={item.status === 'active'} />`
    
    4. **Load nested children on expand**:
       - When a BranchLifecycleBlock is expanded, fetch its children via `getSessionChildrenFn`
       - Use `useQuery` with `enabled: isOpen` so children are only loaded when expanded
       - Render each child as a nested `<BranchLifecycleBlock item={child} jobId={jobId} depth={depth + 1} />`
       - Limit nesting depth to 4 levels to prevent infinite recursion
    
    5. **Indentation for nesting depth**:
       - Each nesting level adds `ml-4` (16px) left margin
       - At depth > 0, add a left border: `border-l-2 border-l-muted` to show nesting visually
       - At depth > 2, reduce the card padding to `py-1.5` to keep things compact
    
    6. **Mobile considerations**:
       - On mobile, reduce indentation: `ml-2` instead of `ml-4`
       - Ensure nested content doesn't overflow: `overflow-hidden max-w-full` on each level
       - Use `useIsMobile()` to conditionally reduce indentation
  </action>
