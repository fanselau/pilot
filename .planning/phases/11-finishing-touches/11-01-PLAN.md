Create `src/core/doctor.ts` — a pure core module (no UI deps) that runs all health checks and returns structured results.

**Types:**
```typescript
interface DoctorCheck {
  name: string;           // e.g. 'binary', 'gsd_dir', 'symlinks'
  status: 'pass' | 'fail' | 'warn';
  message: string;        // human-readable description
  fixable: boolean;       // can --fix auto-fix this?
  fixAction?: string;     // what --fix would do
}

interface DoctorResult {
  checks: DoctorCheck[];
  passed: number;
  failed: number;
  warnings: number;
}
```

**9 checks to implement (reuse patterns from spawn.ts where noted):**

1. **binary** — Check opencode/claude binary exists and is executable. Reuse the `checkBinary` pattern from spawn.ts (check `which opencode`, `which claude`, then default paths `~/.opencode/bin/opencode`, `~/.claude/bin/claude`). Status: pass if found, fail if not. Not fixable.

2. **gsd_dir** — Check `PILOT_GSD_DIR` exists and contains `commands/`, `agents/`, `get-shit-done/` subdirectories. Status: pass if all exist, fail if dir missing, warn if subdirs incomplete. Not fixable.

3. **symlinks** — Scan `$PILOT_PROJECT_DIR/*/` for projects that have `.claude/` or `.opencode/` dirs. For each, check if symlinks (`command/`, `agents/`, `get-shit-done/`) resolve to actual files (use `fs.realpath` or `fs.stat` to detect broken symlinks). Status: pass if all valid, warn with list of broken ones. Fixable: re-create broken symlinks.

4. **git_gc** — Check `gc.auto=0` on all snapshot repos under `~/.local/share/opencode/snapshot/*/` AND `snapshot/global/`. Reuse pattern from `disableSnapshotGc()` in spawn.ts. Use `execa('git', ['-C', repo, 'config', 'gc.auto'])` and check output is "0". Status: pass if all set, warn if any missing. Fixable: set gc.auto=0 on all repos.

5. **memory** — Read `/proc/meminfo` MemAvailable (reuse `getSystemFreeMem` pattern from spawn.ts). Warn if <2GB. Status: pass if >=2GB, warn if <2GB but >=500MB, fail if <500MB. Not fixable.

6. **zombies** — Scan PID files via `scanPidFiles()` pattern. For each, check `/proc/{pid}/status` State field. If 'Z' (zombie), report. Also check for orphaned opencode processes via `execa('pgrep', ['-f', 'opencode'])` or similar — compare with tracked PIDs. Fixable: kill zombies.

7. **stale_pids** — Scan all `gsd-*-pid` files in logDir. For each, read PID and check `isProcessAlive()`. If PID file exists but process is dead, it's stale. Fixable: remove stale PID files.

8. **queue** — Check `$PILOT_QUEUE_FILE` is readable (use `fs.access`). Status: pass if readable, fail if not found, warn if empty. Not fixable.

9. **pilot_dir** — Check `~/.pilot/` exists and is writable. If not, create it. Status: pass if exists, warn if created. Fixable: mkdir.

**`runDoctor(options: { fix: boolean })` function:**
- Runs all 9 checks sequentially (most are fast I/O, no CPU sampling)
- If `fix` is true: after each fixable check that failed/warned, attempt the fix and re-check
- Returns `DoctorResult`
- Must complete in <2 seconds total (no CPU sampling, no polling loops)

**Also export `ensurePilotDir()` as a standalone helper** — other modules (runner log, notifications config) will need to ensure `~/.pilot/` exists. Simple `mkdir(path.join(os.homedir(), '.pilot'), { recursive: true })`.
