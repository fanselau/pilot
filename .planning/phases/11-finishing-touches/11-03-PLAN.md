Create `src/core/cleanup.ts` — pure core module (no UI deps):

**Types:**
```typescript
interface CleanupOptions {
  dryRun: boolean;
  all: boolean;           // aggressive: also clean history, old queue entries
  keepDays: number;       // default 7
}

interface CleanupAction {
  type: 'remove_pid' | 'remove_log' | 'kill_orphan' | 'remove_history' | 'clean_queue';
  target: string;         // file path or PID
  reason: string;         // why this was cleaned
}

interface CleanupResult {
  actions: CleanupAction[];   // what was (or would be) done
  dryRun: boolean;
}
```

**`runCleanup(options: CleanupOptions)` function:**

1. **Stale PID files:** Scan `$PILOT_LOG_DIR/gsd-*-pid` files. For each, read PID and check `isProcessAlive()`. If dead → add action `remove_pid`. If not dryRun → `unlink` the file.

2. **Old log files:** Scan `$PILOT_LOG_DIR/gsd-*.log` files. Check mtime via `fs.stat`. If older than `keepDays` days → add action `remove_log`. If not dryRun → `unlink`. Also scan `~/.pilot/logs/runner-*.log` for old runner logs.

3. **Empty/broken log files:** Scan `$PILOT_LOG_DIR/gsd-*.log`. If size is 0 bytes → add action `remove_log` with reason "empty". If not dryRun → `unlink`.

4. **Orphaned processes:** Use `execa('pgrep', ['-f', 'opencode|claude'])` to find running AI processes. Get their PIDs. Compare against PIDs tracked in `gsd-*-pid` files. Any PID found by pgrep but NOT in a PID file is orphaned → add action `kill_orphan`. If not dryRun → send SIGTERM via `process.kill(pid, 'SIGTERM')`. Wrap pgrep in try/catch — it exits 1 if no matches (that's fine, means no orphans).

5. **If `--all`:**
   - Clean job history: if `pilot-job-history.jsonl` exists and is older than keepDays, truncate to last 100 entries (read all lines, keep last 100, rewrite). Add action `remove_history`.
   - Clean old done/failed queue entries: this is read-only reporting only (we don't modify QUEUE.md here — too risky). Just report count of done/failed entries.

Return `CleanupResult` with all actions taken.
