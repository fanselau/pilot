**Running panel step progress:**

Each Job has `delegationPlan: string | null` (JSON-encoded `DelegationPlan` with `steps: DelegationStep[]`) and `currentStep: number` (0-indexed into the steps array). Use these to show step progress.

In running-panel.tsx, add a helper:
```typescript
function getStepProgress(job: Job): string | null {
  if (!job.delegationPlan) return null;
  try {
    const plan = JSON.parse(job.delegationPlan) as { steps: { command: string; args: string }[] };
    const total = plan.steps.length;
    if (total === 0) return null;
    // currentStep is 0-based index — add 1 for display
    const current = Math.min(job.currentStep + 1, total);
    // Use optional chaining — currentStep might be past array bounds if job just finished
    const stepName = plan.steps[job.currentStep]?.command ?? '…';
    return `Step ${current}/${total}: ${stepName}`;
  } catch { return null; }
}
```

Skip the step line entirely when `delegationPlan` is null (quick tasks, failed delegation) or when steps array is empty.

Add a new line between the elapsed/tokens line and the session title line:

```tsx
  />
) : null}
```

Use `▹` as the step indicator (lighter than ▸, distinguishes from selection indicator). Color it with the running status color (blue), which gets overridden to white when selected (from Plan 01's textColor helper).
