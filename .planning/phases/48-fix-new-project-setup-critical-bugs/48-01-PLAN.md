After the symlinks loop in `setupProject()` (after line 127), add a validation block that checks `gsd-delegate.md` exists in the resolved command directory.

The command directory is: `path.join(config.gsdDir, 'commands')` — that's the target the `.opencode/command` symlink points to.

Add this validation block AFTER the symlinks are created (after the `for (const link of symlinks)` loop), but BEFORE the project command linking step (step 4):

```typescript
// Validate that the linked command directory has the expected flat layout.
// gsd-delegate.md is a sentinel — if it's missing, the GSD installation is outdated.
const commandTarget = path.join(config.gsdDir, 'commands');
const delegatePath = path.join(commandTarget, 'gsd-delegate.md');
const { existsSync } = await import('node:fs');
if (!(existsSync(delegatePath))) {
  result.errors.push(
    `GSD delegate command not found. Your pilot-gsd installation may be outdated.\n` +
    `  Expected: ${delegatePath}\n` +
    `  Hint: Update pilot-gsd submodule or set gsdDir in ~/.pilot/config.json to a working fork.\n` +
    `  The correct layout has flat gsd-*.md files in ${commandTarget}/`,
  );
  return result;
}
```

Note: `existsSync` is not currently imported from `node:fs` in `setup.ts` — it uses the async `access()` helper instead. Use `import('node:fs')` for the dynamic import, or add `existsSync` to the top-level import. Prefer adding it to the static import at the top of the file:

Change line 11:
```typescript
import { mkdir, symlink, readFile, readdir, writeFile, access, stat, lstat, realpath } from 'node:fs/promises';
```

And add a separate sync import:
```typescript
import { existsSync } from 'node:fs';
```

Then use `existsSync(delegatePath)` directly (no dynamic import needed).

Also add a success message to the result when validation passes, so the user knows where commands came from:
```typescript
result.created.push(`Verified GSD command layout: ${commandTarget}`);
```
Place this just after the check (when the file IS found).
