<objective>
Create the shared UI-review lifecycle contract and wire the runner to execute advisory `ui-review` audits only after successful judge completion.

Purpose: Pilot already knows how to recover `ui-phase` from artifact-based hangs, but it has no post-judge UI audit lane. This plan adds the reusable helper rules and the runner pass-path hook that make `ui-review` deterministic, non-blocking, and loop-safe.
Output: `src/core/ui-review.ts`, runner pass-path append logic, advisory artifact recovery, and focused regression coverage.
</objective>

    export function findExistingUiReview(projectDir: string, phaseNumber: number): string | null;
    export function extractPhaseNumberFromStepArgs(args: string): number | null;

      job: Pick<Job, 'scope' | 'delegationPlan'>,
      steps: Array<Pick<JobStep, 'command' | 'args'>>,

    Implement exact rules:

    - `findExistingUiSpec()` keeps the Phase 87 directory-scan behavior (`.planning/phases/<number>-*/<number>-UI-SPEC.md`).
    - `findExistingUiReview()` uses the same directory resolution pattern but looks for `*-UI-REVIEW.md`.
    - `isUiReviewEligible()` returns `eligible: true` when **any** of these are true:
      1. `job.scope === 'phase'` and `job.delegationPlan` parses to `{ intent: { type: 'plan-and-execute', uiPhase: true } }`
      2. any prior step has `command === 'ui-phase'`
      3. `findExistingUiSpec(projectDir, phaseNumber)` finds a file
    - `isUiReviewEligible()` returns `eligible: false` for non-phase jobs, malformed phase numbers, or when none of the signals above are present.
    - `resolveUiArtifactOutcome()` must behave exactly like this:
      - `ui-phase` + `UI-SPEC.md` exists -> `completed`
      - `ui-phase` + no artifact -> `failed`
      - `ui-review` + `UI-REVIEW.md` exists -> `completed`
      - `ui-review` + no artifact -> `skipped`
      - any other command -> `failed`

    Do **not** add a new database column or new LLM decision surface. Per research, eligibility is derived from existing `delegationPlan`, prior steps, and phase artifacts.
