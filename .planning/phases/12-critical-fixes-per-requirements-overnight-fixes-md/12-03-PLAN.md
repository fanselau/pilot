**# Pilot**

Brief description: Autonomous AI development pipeline CLI that monitors running AI sessions, manages a job queue, detects stuck processes, orchestrates project lifecycle commands, and provides a full-screen TUI dashboard. Replaces bash scripts with typed TypeScript for reliability.

**## Quick Start**
```bash
# Install
npm install -g @punchlab/pilot

# Or run from source
git clone https://github.com/punchlab-dev/pilot.git
cd pilot
npm install
npm run build
npm link

# Set up a project
pilot setup ~/dev/my-project

# Check status
pilot status

# View queue
pilot queue

# Start the queue runner
pilot run
```

**## Commands**

Group commands exactly as in the spec's help output (requirements/pilot-cli.md §4 "pilot help"):

Monitoring: status, queue, stuck, log, tail, projects, progress
Setup: setup, update, config
Queue Management: run, stop, add, build
Project Lifecycle: init, plan, execute, verify, quick, debug, research, scope, insert, remove, milestone, todos, map
Dashboard: tui

For each command: one line with name, args, and brief description. Example:
```
pilot status [--verbose]    Dashboard: running, stuck, queued, completed (default command)
```

**## Configuration**

Table of environment variables from spec §4:
| Variable | Default | Description |
PILOT_QUEUE_FILE, PILOT_LOG_DIR, PILOT_STUCK_THRESHOLD, PILOT_PROJECT_DIR, PILOT_GSD_DIR, NO_COLOR

**## Architecture**

Brief overview of the three-layer architecture:
- `core/` — Pure TypeScript data layer (no UI deps). Sessions, queue parsing, stuck detection, process management, project scanning.
- `commands/` — CLI command handlers. Import from core/, render human-readable or JSON output.
- `tui/` — Full-screen Ink/React dashboard. Lazy-loaded only for `pilot tui`.

Key rule: core/ has zero UI dependencies. Import direction is always commands/ → core/ and tui/ → core/.

Key dependencies: commander, picocolors, cli-table3, execa, tree-kill, proper-lockfile, ink, react
