Add three new private helper functions and integrate them into the `launch()` method's step loop:

1. **`scanPhaseDirs(projectDir: string): string[]`** — returns sorted list of phase directory names from `.planning/phases/`. Uses `readdirSync` + filter for `NN-*` pattern. Returns empty array if dir doesn't exist. This is used to diff before/after add-phase.

2. **`verifyStepArtifacts(projectDir: string, step: DelegationStep, prevPhaseDirs: string[]): { ok: boolean; error?: string; newPhaseNumber?: number }`**:
   - For `add-phase` command:
     - Scan `.planning/phases/` after step completes
     - Diff against `prevPhaseDirs` to find newly created directory
     - If new dir found: extract phase number from its name (match `/^(\d+)-/`), return `{ ok: true, newPhaseNumber }`
     - If no new dir found: return `{ ok: false, error: 'add-phase did not create a new phase directory' }`
   - For `plan-phase` command:
     - Extract phase number from `step.args` (first token, e.g. "3" from "3 --auto")
     - Find matching phase directory: pad to 2 digits, glob for `${padded}-*`
     - Check if directory contains at least one `*-PLAN.md` file
     - If yes: `{ ok: true }`. If no: `{ ok: false, error: 'plan-phase N did not create any PLAN.md files' }`
   - For `execute-phase` command:
     - Same phase dir resolution as plan-phase
     - Check if directory contains at least one `*-SUMMARY.md` file
     - If yes: `{ ok: true }`. If no: `{ ok: false, error: 'execute-phase N did not create any SUMMARY.md files' }`
   - For all other commands: `{ ok: true }` (skip verification)

3. **`patchStepArgs(steps: DelegationStep[], fromIndex: number, predictedPhase: number, actualPhase: number): void`** — mutates `steps` array in place:
   - For each step from `fromIndex` onward
   - If step.command is `plan-phase`, `execute-phase`, or `verify-phase`
   - Replace the phase number in `step.args`:
     - Match `/^(\d+)(.*)/` on args
     - If the matched number equals predictedPhase, replace with actualPhase
     - Preserve the rest of the args string (e.g. ` --auto`, ` @path`)
   - Log the patch to stderr: `[runner] Patched ${step.command} args: ${oldArgs} → ${newArgs}`

4. **Integrate into `launch()` step loop** — insert AFTER the existing evaluateStepResult block (around line 233, before `advanceStep`):

```typescript
// Inter-step artifact verification
const verification = verifyStepArtifacts(projectDir, step, prevPhaseDirs);
if (!verification.ok) {
  // Record failure in step record if currentStepRowId is still set
  if (currentStepRowId !== null) {
    const sessionId = findSessionByTitle(title);
    completeStep(currentStepRowId, 'failed', 'artifact-check', verification.error ?? 'Artifact verification failed', sessionId ?? null);
    currentStepRowId = null;
  }
  throw new Error(`Step "${step.command} ${step.args}" artifact check failed: ${verification.error}`);
}

// Dynamic arg patching after add-phase
if (step.command === 'add-phase' && verification.newPhaseNumber !== undefined) {
  // Extract predicted phase from next step args (if they exist)
  if (i + 1 < plan.steps.length) {
    const nextArgs = plan.steps[i + 1].args;
    const predictedMatch = nextArgs.match(/^(\d+)/);
    if (predictedMatch) {
      const predicted = parseInt(predictedMatch[1], 10);
      if (predicted !== verification.newPhaseNumber) {
        patchStepArgs(plan.steps, i + 1, predicted, verification.newPhaseNumber);
      }
    }
  }
}
```
