Create `src/core/queue-store.ts` — the core JSON queue storage module. This replaces queue-parser.ts for all new queue operations.

**File I/O with locking:**
- `ensurePilotDir()` — create `~/.pilot/` if it doesn't exist (use `mkdir -p` equivalent: `fs.mkdir(dir, { recursive: true })`)
- `loadQueue()` — read `~/.pilot/queue.json`, parse, return typed `QueueJsonFile`. If file doesn't exist, return `{ version: 1, items: [], history: [] }`.
- `saveQueue(data: QueueJsonFile)` — write JSON with 2-space indent. Call `ensurePilotDir()` first.
- `withQueueJsonLock<T>(fn: () => Promise<T>)` — wrap fn with `proper-lockfile` lock on the queue.json file path. Stale: 30s, retries: 5, minTimeout: 100, maxTimeout: 1000. If file doesn't exist yet, lock on the pilotDir instead (proper-lockfile needs an existing file to lock on — use `realpath: false` option or lock on the directory).

**CRUD operations (all use withQueueJsonLock internally):**

- `addItem(opts: { project: string; mode: string; description?: string; dependsOn?: string; maxAttempts?: number; meta?: Record<string, unknown> })`: Promise<string>
  - Generate ID with `nanoid(12)` (12 chars — short enough to type, unique enough for <100 items)
  - If `dependsOn` is provided, validate: (a) the referenced item exists in items array and (b) adding this dependency won't create a circular chain. Walk the `dependsOn` chain from the target item — if it ever reaches the new item's project, reject.
  - Append to items array with status 'queued', addedAt = new Date().toISOString(), attempts = 0, maxAttempts = opts.maxAttempts ?? 3
  - Return the generated ID

- `removeItem(id: string)`: Promise<void>
  - Find item in items array by ID
  - If not found, throw `Error('Item not found: <id>')`
  - If status is 'running', throw `Error('Cannot remove running item: <id>')`
  - Remove from items array, save

- `findLaunchable(runningProjects: Set<string>, maxParallel: number, activeCount: number)`: Promise<QueueJsonItem | null>
  - Load queue (no lock needed — read-only)
  - Find first item where: status === 'queued' AND project not in runningProjects AND (dependsOn is null OR dependsOn item exists in history with status 'completed') AND activeCount < maxParallel
  - Return null if none found

- `markRunning(id: string)`: Promise<void>
  - Find item, set status = 'running', startedAt = new Date().toISOString(), attempts++, save

- `markCompleted(id: string)`: Promise<void>
  - Find item, set status = 'completed', completedAt = now
  - Calculate duration: (completedAt - startedAt) in seconds
  - Move item from `items` to `history` as QueueHistoryItem (spread item + duration)
  - Cap history: keep last 100 entries (remove oldest by completedAt)
  - Save

- `markFailed(id: string, error?: string)`: Promise<void>
  - Find item, set status = 'failed', completedAt = now, error = error ?? null
  - Calculate duration
  - Move to history
  - Cap history
  - Save

- `markQueued(id: string)`: Promise<void>
  - Find item, set status = 'queued', startedAt = null (for retry)
  - Save (item stays in items array)

- `getHistory(limit?: number)`: Promise<QueueHistoryItem[]>
  - Load queue, return history array sorted by completedAt desc, sliced to limit (default 100)

- `getItems()`: Promise<QueueJsonItem[]>
  - Load queue, return items array

- `getItemById(id: string)`: Promise<QueueJsonItem | null>
  - Load queue, find by ID in items array

**Circular dependency detection:**
```typescript
function detectCircularDep(items: QueueJsonItem[], newItemId: string, dependsOnId: string): boolean {
  // Walk the chain: dependsOnId → its dependsOn → ... 
  // If we reach an item whose dependsOn would be newItemId, it's circular
  const visited = new Set<string>();
  let current: string | null = dependsOnId;
  while (current !== null) {
    if (visited.has(current)) return true; // cycle in existing chain
    visited.add(current);
    const item = items.find(i => i.id === current);
    if (!item) break;
    current = item.dependsOn;
  }
  return false; // no cycle
}
```

**Important implementation notes:**

- All mutations (add, remove, mark*) should: lock → load → mutate → save → unlock
- Do NOT import from queue-parser.ts. This is a clean replacement.
