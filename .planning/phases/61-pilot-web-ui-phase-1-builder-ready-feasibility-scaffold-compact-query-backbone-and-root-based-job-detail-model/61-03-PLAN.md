**web/src/components/job-detail.tsx** — Main detail component:

Render the `JobDetailSnapshot` DTO in a compact, root-based layout. This is the most important component — it must demonstrate the non-recursive detail model.

Layout structure (top to bottom):
1. **Job Header** — `Card` with:
   - Job ID, project, scope, status badge, verdict badge
   - Description (full text, not truncated)
   - Timestamps: created, started, completed, duration
   - Model profile, provider mode
   - Error message if failed (in a destructive Alert)

2. **Step Timeline** — vertical list/table of steps:
   - Each step: index, command, args, status badge, duration, verdict reason
   - Use `Separator` between steps
   - Active step highlighted with `Progress` or subtle animation

3. **Root Sessions** — section with session summaries:
   - For each root session: `Card` showing title, status, message count, token count, models, latest message preview (200 chars max)
   - Click navigates to session drill-in route

4. **Sub-agent Summaries** — section with compact cards:
   - Use `SubagentCard` component for each
   - Shows: title/role, status, timing, latest answer preview, child count
   - Explicit "View full transcript →" link for drill-in
   - Do NOT inline full sub-agent transcripts

5. **Activity Preview** — bottom section:
   - Show the activityPreview items from the snapshot
   - Each item: timestamp, type icon, role, preview text (300 chars)
   - "Load more" button → calls getSessionActivityFn with pagination
   - Use `Collapsible` for expanding individual items to full content

6. **Live Updates** — wire `useJobDetailStream`:
   - Call `useJobDetailStream(jobId, snapshot.cursor)` from Plan 02
   - When events arrive, invalidate relevant React Query cache keys
   - Show subtle "Updated X seconds ago" indicator
   - Status badge updates in real-time when job completes/fails

- Latest message preview with text truncation
- `Button` or `Link` for "View transcript →" drill-in
- Does NOT show full transcript content
