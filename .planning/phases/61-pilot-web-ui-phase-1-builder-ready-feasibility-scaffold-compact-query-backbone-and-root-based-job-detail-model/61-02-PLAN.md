**web/src/lib/sse.ts** — SSE streaming hook for live job detail updates:

Implement a lightweight SSE mechanism using TanStack Start's server function + client polling pattern:
- Server function `streamJobDetailFn` returns events via `getJobDetailEvents`
- Client hook `useJobDetailStream(jobId, initialCursor)` uses `setInterval` to poll the server function every 2-3 seconds
- On each poll, fetch new events since last cursor, merge into React Query cache
- Return `{ events, isConnected, lastUpdate }` reactive state

This is intentionally NOT SSE over HTTP (which requires more infrastructure) — it's server-function polling that acts like a lightweight stream. The requirements say "lightweight, explicit model" and "SSE-style stream backed by server-side polling" — this satisfies that.

Alternative: If TanStack Start supports actual SSE/streaming responses natively, use that instead. Check if `createServerFn` supports streaming.

The hook should work with TanStack React Query:
```typescript
export function useJobDetailStream(jobId: string, initialCursor: string) {
  const [cursor, setCursor] = useState(initialCursor)
  
  const { data } = useQuery({
    queryKey: ['job-events', jobId, cursor],
    queryFn: () => getJobDetailEventsFn({ data: { jobId, cursor } }),
    refetchInterval: 3000,  // poll every 3s
    enabled: !!jobId,
  })

  // When new events arrive, update cursor
  useEffect(() => {
    if (data?.cursor) setCursor(data.cursor)
  }, [data?.cursor])

  return { events: data?.events ?? [], cursor }
}
```

**web/src/app.tsx** — App entry point with React Query provider:
```typescript
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { RouterProvider } from '@tanstack/react-router'
import { getRouter } from './router'

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 5000,
      refetchOnWindowFocus: true,
    },
  },
})

export function App() {
  const router = getRouter()
  return (
    <QueryClientProvider client={queryClient}>
      <RouterProvider router={router} />
    </QueryClientProvider>
  )
}
```
