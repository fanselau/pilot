**Step 1: Create `web/public/` directory** if it doesn't exist:
```bash
mkdir -p web/public
```

**Step 2: Create `web/public/favicon.svg`**
Copy the brand icon from `web/src/assets/brand/autopilot-icon.svg` but replace `currentColor` with a specific color for standalone favicon context. Use `#171717` (neutral-800, the light-theme primary) as the fill color. Keep the same 32x32 viewBox and paths.

**Step 3: Generate raster favicons using ImageMagick**
Check if ImageMagick `convert` is available. If available:
```bash
# ICO (16x16 + 32x32)
convert web/public/favicon.svg -define icon:auto-resize=16,32 web/public/favicon.ico

# Apple Touch Icon (180x180, SOLID background — transparent = black on iOS)
# Use a light neutral background (#f5f5f5) with the dark icon
convert web/public/favicon.svg -resize 180x180 -gravity center -background "#f5f5f5" -extent 180x180 web/public/apple-touch-icon.png

# Android/PWA icons
convert web/public/favicon.svg -resize 192x192 -background none -flatten web/public/icon-192.png
convert web/public/favicon.svg -resize 512x512 -background none -flatten web/public/icon-512.png
```

If ImageMagick is NOT available: Create minimal placeholder PNGs and note in the summary that raster favicons need manual generation. The SVG favicon alone covers modern browsers.

**Step 4: Create `web/public/site.webmanifest`**
```json
{
  "name": "AutoPilot",
  "short_name": "AutoPilot",
  "icons": [
    { "src": "/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ],
  "theme_color": "#171717",
  "background_color": "#ffffff",
  "display": "standalone"
}
```

**Step 5: Wire favicon link tags into `web/src/routes/__root.tsx`**
Add favicon links to the `head()` function's `links` array:
```typescript
links: [
  { rel: 'stylesheet', href: appCss },
  { rel: 'icon', type: 'image/svg+xml', href: '/favicon.svg' },
  { rel: 'icon', type: 'image/x-icon', href: '/favicon.ico' },
  { rel: 'apple-touch-icon', sizes: '180x180', href: '/apple-touch-icon.png' },
  { rel: 'manifest', href: '/site.webmanifest' },
],
```

Also add theme-color meta tag:
```typescript
meta: [
  { charSet: 'utf-8' },
  { name: 'viewport', content: 'width=device-width, initial-scale=1' },
  { title: 'AutoPilot' },
  { name: 'theme-color', content: '#171717' },
],
```
