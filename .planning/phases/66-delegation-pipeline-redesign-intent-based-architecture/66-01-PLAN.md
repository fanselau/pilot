<objective>
Replace the step-based delegation types and delegation AI module with intent-based architecture.

Purpose: The current delegation outputs `DelegationStep[]` (command strings), which the runner loops through sequentially with hardcoded special cases. This is fragile and doesn't scale. Intent-based delegation outputs a single typed intent object, making the runner's workflow logic explicit and type-safe.

Output: New `DelegationIntent` union type in types.ts, rewritten `delegate.ts` that loads a prompt from `src/prompts/delegate.md` and parses intent JSON output, and the delegation prompt itself.
</objective>

**Modify `parseDelegationOutput()` → `parseIntentOutput()`:**

Rename and rewrite to parse `DelegationResult` instead of `DelegationPlan`:

```typescript
function parseIntentOutput(content: string): DelegationResult {
  // 1. Extract JSON from ```json ... ``` block, or use raw content
  const jsonBlockMatch = content.match(/```json\s*\n([\s\S]*?)\n```/);
  const jsonStr = jsonBlockMatch ? jsonBlockMatch[1] : content.trim();

  // 2. Parse JSON
  const parsed = JSON.parse(jsonStr);

  // 3. Validate: must have intent.type matching one of the valid types
  const validTypes = ['quick', 'init-project', 'new-milestone', 'plan-and-execute', 'execute-only', 'audit-milestone', 'noop'];
  if (!parsed.intent || !validTypes.includes(parsed.intent.type)) {
    throw new Error(`Invalid intent type: ${parsed.intent?.type}`);
  }

  // 4. Type-specific field validation:
  //    - quick: must have description (string)
  //    - init-project: must have prdPath (string)
  //    - new-milestone: must have prdPath (string)
  //    - plan-and-execute: must have phaseNumber (number)
  //    - execute-only: must have phaseNumber (number)
  //    - audit-milestone: must have version (string)
  //    - noop: must have reason (string)

  return {
    intent: parsed.intent as DelegationIntent,
    reasoning: typeof parsed.reasoning === 'string' ? parsed.reasoning : '',
  };
}
```

**Add parse failure retry:**

In `waitForDelegationResult()` or `attemptDelegation()`, if `parseIntentOutput()` throws, inject "Your previous attempt produced invalid JSON: `<error>`" into a second attempt's prompt args:

```typescript
async function delegate(job: Job, projectDir: string): Promise<DelegationResult> {
  try {
    return await attemptDelegation(job, projectDir, 1);
  } catch (firstErr) {
    // If parse failure, retry once with error context
    if (errMsg(firstErr).includes('Failed to parse') || errMsg(firstErr).includes('Invalid intent')) {
      try {
        return await attemptDelegation(job, projectDir, 2, `Your previous attempt produced invalid JSON: ${errMsg(firstErr)}`);
      } catch (retryErr) {
        throw new Error(`${errMsg(retryErr)}. Check project setup with: pilot doctor --project ${projectDir}`);
      }
    }
    throw new Error(`${errMsg(firstErr)}. Check project setup with: pilot doctor --project ${projectDir}`);
  }
}
```
