  1. Create src/tui/widgets/sparkline.ts:
     - Pure function (no UI deps, returns a string):
       ```typescript
       const BLOCKS = ['▁', '▂', '▃', '▄', '▅', '▆', '▇', '█'];

       export function sparkline(data: number[], width?: number): string {
         if (data.length === 0) return '';
         const values = width && data.length > width ? data.slice(-width) : data;
         const max = Math.max(...values, 1); // avoid division by zero
         return values.map(v => {
           const idx = Math.round((v / max) * (BLOCKS.length - 1));
           return BLOCKS[Math.min(idx, BLOCKS.length - 1)];
         }).join('');
       }
       ```
     - Accepts array of numbers, optional width (truncates to last N points)
     - Returns single-line string of Unicode block characters

  2. Create src/tui/widgets/pulse-dot.tsx:
     - SolidJS component using setInterval to toggle color every 1s
     - Uses `createSignal` for the toggle state
     - Start interval on mount, clear on cleanup
     - Renders: `<text content="●" fg={bright() ? statusColors.running : statusColors.runningDim} />`
     - Props: `{ active?: boolean }` — if not active, render steady dim dot
     ```tsx
     import { createSignal, onMount, onCleanup, Show } from 'solid-js';
     import { statusColors } from '../theme.js';

     export function PulseDot(props: { active?: boolean }) {
       const [bright, setBright] = createSignal(true);

       let timer: ReturnType<typeof setInterval> | null = null;

       onMount(() => {
         if (props.active !== false) {
           timer = setInterval(() => setBright(b => !b), 1000);
         }
       });

       onCleanup(() => {
         if (timer) clearInterval(timer);
       });

       return (
         <text
           content="●"
           fg={props.active !== false
             ? (bright() ? statusColors.running : statusColors.runningDim)
             : statusColors.pending
           }
         />
       );
     }
     ```

  3. Create src/tui/widgets/scrollable.tsx:
     - Wrapper component that uses OpenTUI's `<scrollbox>` element
     - Manages scroll position signal
     - Accepts: `{ children: JSX.Element, height: number, follow?: boolean }`
     - If `follow` is true, auto-scrolls to bottom when content changes (use `stickyScroll: true, stickyStart: 'bottom'`)
     - The scrollbox props map directly to OpenTUI's ScrollBox:
       ```tsx
       import type { JSX } from 'solid-js';

       export function Scrollable(props: {
         children: JSX.Element;
         height?: number;
         follow?: boolean;
       }) {
         return (
           <scrollbox
             height={props.height}
             stickyScroll={props.follow ?? false}
             stickyStart="bottom"
             viewportCulling={true}
           >
             {props.children}
           </scrollbox>
         );
       }
       ```

  IMPORTANT: sparkline.ts is pure TypeScript (no JSX, no UI deps). pulse-dot.tsx and scrollable.tsx are SolidJS components (.tsx).

  IMPORTANT: Do NOT over-engineer the scrollable. OpenTUI's `<scrollbox>` element handles virtual scrolling natively. The Scrollable widget is a thin wrapper that sets sensible defaults.
