  <files>src/tui/index.ts, src/tui/app.tsx</files>
  <action>
  1. Create src/tui/index.ts — the entry point:
     ```typescript
     import { render } from '@opentui/solid';
     import { App } from './app.js';

     export async function startTui(opts: { interval?: number }) {
       return new Promise<void>((resolve) => {
         render(
           () => <App interval={opts.interval ?? 3} />,
           {
             targetFps: 30,
             exitOnCtrlC: false,  // we handle Ctrl+C ourselves
             gatherStats: false,
             autoFocus: false,
           },
         );
       });
     }
     ```

  2. Create src/tui/app.tsx — root component:
     - Use `@opentui/solid` hooks: `useKeyboard`, `useRenderer`, `useTerminalDimensions`
     - Create state store via `createPilotState()`
     - Set up data pollers with `createPoller`:
       - Queue/running poll: 1s interval → updates queue, running signals
       - Completed poll: 5s interval → updates completed signal
       - Session enrichment poll: 2s interval → updates token/message signals
     - Start pollers in `onMount`, stop in `onCleanup`
     - Set up global keyboard handler:
       - `q` or Ctrl+C → renderer.destroy(), resolve promise
       - `?` → toggle help overlay
       - `Esc` → close overlays / navigate back
       - `Tab` → cycle panel focus
       - `s` → toggle split view
       - `1` → dashboard, `2` → detail (if job selected), `3` → split
     - Render layout:
       ```tsx
       <box flexDirection="column" width={dims().width} height={dims().height}>
         <StatusBar queue={state.queue()} running={state.running()} completed={state.completed()} />
         <box flexGrow={1}>
           <Switch>
             <Match when={state.view() === 'dashboard'}><box><text content="Dashboard placeholder" /></box></Match>
             <Match when={state.view() === 'detail'}><box><text content="Detail placeholder" /></box></Match>
             <Match when={state.view() === 'split'}><box><text content="Split placeholder" /></box></Match>
           </Switch>
         </box>
         <Show when={state.showHelp()}><HelpOverlay /></Show>
         <FooterBar view={state.view()} panelFocus={state.panelFocus()} />
       </box>
       ```
     
     IMPORTANT: Use lowercase JSX elements (`<box>`, `<text>`, `<scrollbox>`) — this is the OpenTUI/Solid convention (intrinsic elements map to OpenTUI VNodes). Do NOT use PascalCase Box/Text imports from @opentui/core — those are for the imperative API.

     IMPORTANT: Import from '@opentui/solid' for hooks (useKeyboard, useRenderer, useTerminalDimensions, render). Import Switch/Match/Show/createSignal etc from 'solid-js'.
  </action>
