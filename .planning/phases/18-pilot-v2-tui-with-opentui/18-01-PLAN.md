       - `"dev": "bun run src/index.ts"` (replace tsx with bun)
       - `"test": "bun test"` OR keep vitest (vitest works with Bun — keep vitest for compatibility)
       - `"lint": "tsc --noEmit"` (keep for type checking)
     - Remove `tsx` from devDependencies (Bun handles TS natively)

       - `"@types/bun": "latest"` (for Bun type definitions)
     - Remove `postbuild` script that injects shebang for node (Bun uses `#!/usr/bin/env bun`)

  2. Update tsconfig.json:
     - Keep `"module": "Node16"` and `"moduleResolution": "Node16"` (Bun supports these)
     - Change `"jsx": "react-jsx"` to `"jsx": "preserve"` (SolidJS uses its own JSX transform via Bun)
     - Remove `"jsxImportSource": "react"` — will add solid-js config when TUI code is written
     - Actually: for SolidJS with Bun, use `"jsx": "react-jsx", "jsxImportSource": "solid-js"` in tsconfig
     - Keep everything else the same

     ```toml
     [install]
     peer = false
     ```

  4. Keep vitest.config.ts as-is (vitest works under Bun)
