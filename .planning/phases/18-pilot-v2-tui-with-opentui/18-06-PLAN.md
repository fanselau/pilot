  <files>src/tui/components/log-panel.tsx, src/tui/components/info-panel.tsx</files>
  <action>
  1. Create src/tui/components/log-panel.tsx:
     - Bordered box with title "Session Log" (or "Live Log: #id" in split view)
     - Scrollable container showing session messages
     - Each message: `[timestamp] role: content`
       - Timestamp: minutes:seconds since session start
       - Assistant messages: show tool calls in dim brackets
       - User messages: show content (usually short prompts)
     - Follow mode: when enabled, auto-scroll to bottom (use Scrollable with follow=true)
     - Search: when search query is set, highlight matching text
       - Matched lines get a different background color
       - `n` jumps to next match, `N` jumps to previous
       - Track `matchIndices: number[]` and `currentMatchIdx: number`
     - Message loading: On mount + on interval (500ms when tailing), call `fetchJobMessages(sessionTitle, since)`
       - Pass `since` as the timestamp of the last loaded message to get incremental updates
       - Append new messages to existing list
     - Props: `{ sessionTitle: string, follow: boolean, searchQuery: string, height: number }`
     - Format message content:
       - Truncate individual messages to avoid massive log entries
       - Dim timestamps (theme.muted)
       - Tool/file references in dim color
       - Content in normal fg

  2. Create src/tui/components/info-panel.tsx:
     - Bordered box with title "Info"
     - Fixed width (~30 chars or flexBasis)
     - Shows job metadata in a vertical list:
       ```
       Status:  ● Running (with PulseDot if running)
       Project: toolbird
       Scope:   phase
       Created: 20:14 UTC
       Duration: 4m32s
       Session: ses_a1b2c3

       ── Tokens ──
       Input:   8,421
       Output:  3,982
       Total:   12,403
       ▁▂▃▅▇█▅▃▂▁ usage/min
       ```
      - Token sparkline: track token usage over time (each poll adds a data point)
        - Store as `tokenHistory: number[]` signal, append total tokens each poll
        - Render with `sparkline(tokenHistory(), 20)` for last 20 data points
      - Files Modified section (below sparkline):
        - Header: `── Files Modified ──`
        - Parse from job's most recent git diff: run `git diff --name-status HEAD~N` in the project dir
          where N = number of commits in this session (from job.commits or default 1)
        - Format each file: `+ path` for added (green), `~ path` for modified (yellow), `- path` for deleted (red)
        - If git data unavailable (job still running, no commits yet), show "No changes yet" in muted text
        - Limit display to first 10 files, show `+N more` if truncated
        - Example:
          ```
          ── Files Modified ──
          + src/auth/callback.ts
          ~ src/routes/index.ts
          ~ package.json
          ```
      - Props: `{ job: Job, tokens: { input: number, output: number } | undefined }`
      - Format numbers with commas: `8,421`
      - Elapsed time updates every 1s (same pattern as RunningPanel)

  IMPORTANT: LogPanel loads messages incrementally. First load gets all messages, subsequent polls only get messages with `time_created > lastTimestamp`. This is critical for performance — some sessions have thousands of messages.

  IMPORTANT: Do NOT parse or render markdown/HTML from message content. Just display raw text with basic formatting (timestamps dim, content normal).

   - InfoPanel shows "Files Modified" section with +/~/- prefixes when git data available
