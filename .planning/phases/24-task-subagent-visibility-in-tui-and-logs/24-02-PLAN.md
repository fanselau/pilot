**1. Update the SessionSection interface** to support nesting and subagent type:

```typescript
export interface SessionSection {
  title: string;

```

**2. Add import of `getChildSessions`** at the top of the imports from `../../core/opencode-db.js`.

**3. Create a helper `resolveChildSections(sessionId, parts, depth)`** that:
- Accepts the parent sessionId, the parts array for that session, and current depth
- If depth >= 2, returns empty (max 2 levels)
- Finds all task-type parts in the parts array: `parts.filter(p => p.type === 'tool' && p.tool === 'task')`
- If no task parts, returns empty array
- Calls `getChildSessions(sessionId)` to retrieve child sessions. **No time-proximity matching is needed**: opencode stores `parent_id` on every session spawned by a `task` tool call, so `getChildSessions(sessionId)` returns exactly the right set of children by database join — no ambiguity, no heuristics.
- For each child session returned: fetches parts via `getSessionParts(child.id)`, extracts agentType from the child's title (look for patterns like `gsd-planner`, `gsd-executor` in the title string — e.g. a title like `pilot-delegate-abc1-gsd-planner-1` → agentType `'gsd-planner'`; fallback to `'subagent'` if no match)
- Returns array of SessionSection with type `'subagent'`, agentType set, parts set, and recursive children (depth+1)

```typescript
function resolveChildSections(
  sessionId: string,
  parts: SessionPart[],
  depth: number,
): SessionSection[] {
  if (depth >= 2) return [];
  
  const taskParts = parts.filter(p => p.type === 'tool' && p.tool === 'task');
  if (taskParts.length === 0) return [];
  
  const childSessions = getChildSessions(sessionId);
  if (childSessions.length === 0) return [];
  
  return childSessions.map((child) => {
    const childParts = getSessionParts(child.id);
    // Extract agent type from title (e.g. contains "gsd-planner", "gsd-executor")
    let agentType = 'subagent';
    const agentMatch = child.title.match(/gsd-(\w+(?:-\w+)*)/);
    if (agentMatch) agentType = agentMatch[0]; // e.g. "gsd-planner"
    
    const grandchildren = resolveChildSections(child.id, childParts, depth + 1);
    
    return {
      title: child.title,
      type: 'subagent' as const,
      agentType,
      parts: childParts,
      children: grandchildren.length > 0 ? grandchildren : undefined,
    };
  });
}
```

**4. Update `fetchJobParts`** to call `resolveChildSections` after fetching each section's parts:

Note: The `since` filter applies only to the top-level parts. Child sections always do full fetches (they're not in the incremental polling path directly).

**Current rendering** in the `<For each={sections()}>` block renders each section's parts flat.

**New rendering** should:

Create a helper component (or inline JSX) `SectionContent` that renders a section and optionally its children recursively (but with a depth cap to avoid infinite loops in the JSX).

The simplest approach that avoids recursive JSX components: render up to 2 levels inline.

**Section header rendering** — find the existing section header `content={...}` expression in detail.tsx (around line 311) which currently uses a two-branch ternary `section.type === 'delegation' ? '── Delegation ──' : '── Execution: ... ──'`. The `else` branch produces `'── Execution: undefined ──'` for any type that isn't `'delegation'`, including the new `'subagent'` type. Replace this two-branch ternary with a three-branch ternary:

- `'delegation'` → `── Delegation ──`
- `'subagent'` → `── Subagent: {agentType} ──` (use dimmer color, e.g. `theme.border`)
- else (execution) → `── Execution: {command} ──`

Updated ternary:
```tsx
content={section.type === 'delegation'
  ? `  ── Delegation ──`
  : section.type === 'subagent'
    ? `  ── Subagent: ${section.agentType ?? 'subagent'} ──`
    : `  ── Execution: ${section.command ?? 'unknown'} ──`}
```

This must be applied to **both** the top-level section header AND the child section header rendering below. If you add child section headers as inline JSX (as shown in the action), write them directly as the three-branch form — do not reuse the old two-branch expression.

**Indentation for child sections**: prefix all text with 2 extra spaces. The simplest approach is to render child section headers and parts with `paddingLeft={2}` on the wrapping box.

Add after the existing section parts rendering, still inside `<For each={sections()}>`:

```tsx
{/* Child sections (subagent tasks) */}
<Show when={section.children && section.children.length > 0}>
  <For each={section.children ?? []}>
    {(child) => (
      <box flexDirection="column" paddingLeft={2}>
        {/* Child section header */}
        <text
          content={`  ── Subagent: ${child.agentType ?? 'subagent'} ──`}
          fg={theme.border}
        />
        {/* Child parts */}
        <Show when={child.parts.length > 0} fallback={
          <text content="    (no activity yet)" fg={theme.muted} />
        }>
          <For each={child.parts}>
            {(part) => {
              const lines = formatPartLines(part);
              if (!lines) return null;
              return (
                <box flexDirection="column">
                  <For each={lines}>
                    {(line) => (
                      <text content={`  ${line.text}`} fg={line.color} />
                    )}
                  </For>
                </box>
              );
            }}
          </For>
        </Show>
        {/* Grandchild sections (level 2, no further recursion) */}
        <Show when={child.children && child.children.length > 0}>
          <For each={child.children ?? []}>
            {(grandchild) => (
              <box flexDirection="column" paddingLeft={2}>
                <text
                  content={`    ── Subagent: ${grandchild.agentType ?? 'subagent'} ──`}
                  fg={theme.border}
                />
                <For each={grandchild.parts}>
                  {(part) => {
                    const lines = formatPartLines(part);
                    if (!lines) return null;
                    return (
                      <box flexDirection="column">
                        <For each={lines}>
                          {(line) => (
                            <text content={`    ${line.text}`} fg={line.color} />
                          )}
                        </For>
                      </box>
                    );
                  }}
                </For>
              </box>
            )}
          </For>
        </Show>
      </box>
    )}
  </For>
</Show>
```
