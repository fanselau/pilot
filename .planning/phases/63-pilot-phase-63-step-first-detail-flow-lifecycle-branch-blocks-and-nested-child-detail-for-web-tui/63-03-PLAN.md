<objective>
Restructure web routing so child drill-in behaves like a true nested page.

Purpose: The current route stack appends child detail below parent content, which makes drill-in feel accidental. This plan turns `/jobs/$jobId` into a layout route, moves parent detail into an index route, and makes child session detail the primary content for nested routes.

Output: New layout/index route split, upgraded child session route UX, regenerated route tree, and route contract tests.
</objective>
