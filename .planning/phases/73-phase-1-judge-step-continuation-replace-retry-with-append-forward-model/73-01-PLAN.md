   For the migration, add ALTERs in `initDb()` after table creation:
   ```typescript
   // Migration: add source column to job_steps (if not exists)
   try { db.exec("ALTER TABLE job_steps ADD COLUMN source TEXT NOT NULL DEFAULT 'delegation'"); } catch { /* already exists */ }
   try { db.exec("ALTER TABLE job_steps ADD COLUMN reason TEXT"); } catch { /* already exists */ }
   try { db.exec("ALTER TABLE job_steps ADD COLUMN error TEXT"); } catch { /* already exists */ }
   ```
