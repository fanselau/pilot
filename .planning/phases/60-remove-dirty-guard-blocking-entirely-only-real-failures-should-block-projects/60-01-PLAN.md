<objective>
Remove dirty-guard launch blocking from the runner, delete the provenance-aware dirty classification system, and clean up related types/DB/CLI flag.

Purpose: Dirty worktrees should never block job launch. Only real failures (build, execution, verification) should block projects. The runner still records `startedDirty` as informational metadata for undo safety context, but it no longer refuses to launch.

Output: Runner launches jobs regardless of worktree state, `classifyDirtyStart` and `ProjectDirtyBaseline` are deleted, `--force-dirty` flag removed from CLI.
</objective>
