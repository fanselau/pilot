    **1. Create `src/core/notify-backends/types.ts`:**

    ```typescript
    export type NotifyBackendKind = 'kimaki' | 'openclaw-agent-deliver' | 'webhook' | 'telegram';

    export type DetectResult = 'detected' | 'not-found' | 'available' | 'not-configured';

    export interface NotifyResult {
      ok: boolean;
      error?: string;
    }

    export type NotifyRoute =
      | { kind: 'kimaki'; sessionId?: string; channelId?: string }
      | { kind: 'openclaw-agent-deliver'; agentId: string; channel: string; to: string; accountId?: string }
      | { kind: 'webhook'; url: string; headers?: Record<string, string> }
      | { kind: 'telegram'; chatId: string };

    export interface NotifyBackend {
      kind: NotifyBackendKind;
      displayName: string;
      deliver(route: NotifyRoute, prompt: string, job: { id: string; project: string; status: string; description: string; startedAt: string | null; completedAt: string | null; error: string | null }): Promise<NotifyResult>;
      detect(): Promise<DetectResult>;
      validateConfig(): string | null;
    }
    ```

    The `job` parameter in `deliver()` uses a minimal shape (not full `Job` type) to avoid circular imports. The `NotifyRoute` is a discriminated union on `kind`. At least one of `sessionId` or `channelId` must be present for kimaki routes (validated at queue time, not at type level).

    **2. Create `src/core/notify-backends/kimaki.ts`:**
    - Implements `NotifyBackend` with `kind: 'kimaki'`, `displayName: 'Kimaki (Discord)'`
    - `deliver()`:
      - If `route.kind !== 'kimaki'` return `{ ok: false, error: 'wrong backend kind' }`
      - Extract `sessionId` and `channelId` from route
      - If `sessionId`: args = `['send', '--session', sessionId, '--prompt', prompt]`
      - Else if `channelId`: args = `['send', '--channel', channelId, '--prompt', prompt]`
      - Else: return `{ ok: false, error: 'kimaki route missing sessionId and channelId' }`
      - Call `execa('kimaki', args, { timeout: 30_000, reject: false })`
      - Return `{ ok: true }` on exitCode 0, `{ ok: false, error: <stderr detail> }` otherwise
      - Catch non-ENOENT errors, return `{ ok: false, error: message }`
      - On ENOENT: return `{ ok: false, error: 'kimaki binary not found on PATH' }`
    - `detect()`: `execa('kimaki', ['--version'], { timeout: 5_000, reject: false })` → `'detected'` on exit 0, `'not-found'` otherwise
    - `validateConfig()`: return `null` (no global config needed)

    ```typescript
    import type { NotifyBackendKind, NotifyBackend } from './types.js';
    import { kimakiBackend } from './kimaki.js';
    import { openclawBackend } from './openclaw.js';
    import { webhookBackend } from './webhook.js';
    import { telegramBackend } from './telegram.js';
    import { loadConfigFile, _resetConfigCache } from '../config.js';
    ```

    Static backend map:
    ```typescript
    const BACKENDS: Record<NotifyBackendKind, NotifyBackend> = {
      kimaki: kimakiBackend,
      'openclaw-agent-deliver': openclawBackend,
      webhook: webhookBackend,
      telegram: telegramBackend,
    };
    ```

    Exported functions:
    - `getBackend(kind: NotifyBackendKind): NotifyBackend | null` — look up from `BACKENDS`, return null if unknown kind
    - `getAllBackends(): NotifyBackend[]` — `Object.values(BACKENDS)`
    - `getEnabledBackends(): NotifyBackendKind[]` — read `loadConfigFile()?.notifications?.backends` as `string[]`, filter to valid `NotifyBackendKind` values, return. If `notifications.backends` is not set (legacy config), return empty array `[]`.
    - `enableBackend(kind: NotifyBackendKind): void` — read current config file (via `loadConfigFile()`), get current backends array (or `[]`), add `kind` if not present, write back to config file using `writeConfigFile()` pattern (read file, parse JSON, set `notifications.backends`, write back), call `_resetConfigCache()`
    - `disableBackend(kind: NotifyBackendKind): void` — same pattern, remove `kind` from array, write, call `_resetConfigCache()`
    - `getBackendConfig(kind: NotifyBackendKind): Record<string, unknown>` — read `loadConfigFile()?.notifications?.[kind]` (handle the 'openclaw-agent-deliver' key as 'openclaw'), return as record or empty object
    - `setBackendConfig(kind: NotifyBackendKind, key: string, value: unknown): void` — read config file, set `notifications[configKey][key] = value` where `configKey` maps kind to config section name ('openclaw-agent-deliver' → 'openclaw', others use kind directly), write back, call `_resetConfigCache()`

    For writing config, use a private `writeConfigNotifications()` helper that:
    1. Reads the raw config file from `~/.pilot/config.json` (same path as `loadConfigFile()`)
    2. Parses JSON
    3. Modifies `notifications` section
    4. Writes back with `JSON.stringify(config, null, 2)`
    5. Calls `_resetConfigCache()`

    Use the config file path from the `PILOT_CONFIG_FILE` env var fallback or default `~/.pilot/config.json` — follow the same resolution as `loadConfigFile()`.
