   b. **"refresh merges missing fields into existing opencode.json"**:
      - Create an opencode.json with only `{ "custom": "value" }`
      - Call `setupProject(dir, { refresh: true })`
      - Read opencode.json, assert it has BOTH `custom: "value"` AND `permission.read.**` from template
      - Assert existing user values are preserved

   c. **"refresh with force overwrites opencode.json entirely"**:
      - Create an opencode.json with `{ "custom": "value" }`
      - Call `setupProject(dir, { refresh: true, force: true })`
      - Read opencode.json, assert it matches template exactly (no `custom` key)

   d. **"refresh skips real directories (not symlinks) — no data loss"**:
      - Create a real `.opencode/command/` directory (not symlink)
      - Call `setupProject(dir, { refresh: true })`
      - Assert the real directory still exists (not deleted)
      - Assert result.skipped contains data loss warning

   e. **"without refresh, behavior unchanged — symlinks are skipped"**:
      - Set up a project with existing symlinks
      - Call `setupProject(dir)` (no options)
      - Assert symlinks are untouched (still point to original target)
