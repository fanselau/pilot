<objective>
Fix redelegation/nested agent attribution so that `pilot log`, web UI branch headers, and tool call displays preserve meaningful agent identity instead of collapsing to generic "subagent" labels.

Purpose: Operators need to see which agent actually produced which work when debugging nested/redelegated job flows. Currently, re-delegation sessions (pilot-redelegate-*), delegation sessions (pilot-delegate-*), and child sessions spawned by GSD agents all lose their identity and appear as generic "subagent" or "Execution" labels.

Output: Fixed attribution in 4 surfaces (CLI log child headers, CLI log tool call display, web UI branch headers, web UI semantic type resolution) with regression tests.
</objective>
