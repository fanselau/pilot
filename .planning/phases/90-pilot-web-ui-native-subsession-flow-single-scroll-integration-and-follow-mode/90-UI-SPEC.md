## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`), tight inline chip padding |
| sm | 8px | Row vertical padding (`py-2`), compact header padding (`px-2 py-2`) |
| md | 16px | Default horizontal section padding (`px-4`), card content padding |
| lg | 24px | Section vertical rhythm (`space-y-6`) |
| xl | 32px | Layout column gaps, major content sections |
| 2xl | 48px | Reserved — page-level separation |
| 3xl | 64px | Reserved — not used in timeline/detail surfaces |

Exceptions:
- Sticky header row padding is `px-3 py-1` (12px / 4px) — tighter than standard `md` to maximise content density
- Nested subsession left indent: `pl-2 ml-2 sm:pl-3 sm:ml-4` — depth-progressive, starts at 8px
- Follow mode bar: `px-3 py-1` on pill CTA — deliberate compact touch target
- Step section depth indent (`border-l-2 pl-2`) — 8px fixed across all depths for scan-ability

- Running / active: `--info` (blue-500)

- depth 0: `bg-background/95`
- depth 1: `bg-slate-50/30 dark:bg-slate-900/15`

Semantic type bgClass / borderClass sourced from `SEMANTIC_TYPE_CONFIG` in `step-semantics.ts` — must remain consistent across all surfaces (sticky headers, sidebar, summary cards).

## Interaction Contracts

These are the core interaction contracts for Phase 90's three named features:

### 1. Native Subsession Flow

**Goal:** Subsessions (child sessions / BranchLifecycleBlocks) render inline in the single-scroll flow — no separate route, no modal, no card chrome that breaks scroll continuity.

| Interaction | Behaviour |
|-------------|-----------|
| Expand subsession | Collapsible open; content slides into the single scroll document flow directly below the header trigger |
| Collapse subsession | Content collapses; sticky header remains visible at correct depth stacking position |
| Active subsession (status=active) | Expands by default when depth < 2; depth ≥ 2 defaults collapsed |
| Completed/done subsession | Defaults collapsed — glanceable identity row only |
| Max depth (4) | No further child queries or renders beyond MAX_DEPTH=4 |
| Nested sticky headers | Each level uses `position: sticky` with `top` = `(depth + 1) × 2.25rem`; z-index decrements by depth (z-30 → z-20 → ...) |
| Trigger chevron | Rotates 90° on open (`rotate-90`); smooth 200ms CSS transition |
| Collapsed identity row | Must show: semantic icon + label + status badge + role badge (if present) + duration + model name (truncated to 100px) |

### 2. Single-Scroll Integration

**Goal:** The full job execution story — step groups + nested subsessions — is a single continuous-scroll document. No tabs, no pagination, no route transitions required to read.

| Interaction | Behaviour |
|-------------|-----------|
| Step sections | Rendered as `<section>` elements with `id="step-section-{idx}"` and `data-step-index` |
| Sidebar click (desktop) | `scrollIntoView({ behavior: 'smooth', block: 'start' })` on target section; auto-follow cancels |
| Scroll-spy | IntersectionObserver with `rootMargin: '-10% 0px -70% 0px'`; fires `onVisibleStepChange` to sidebar |
| Virtualization threshold | 200 items triggers `@tanstack/react-virtual`; scroll-spy disabled in virtual mode |
| New item highlight | `animate-highlight-fade` class (1.5s sky-500/10 → transparent) on items appearing after initial load |
| Step sticky header | `sticky top-0 backdrop-blur z-30`; depth-specific pastel bg + bottom border in semantic color |
| Subsession sticky header | `sticky top-{(depth+1)*2.25rem}` with descending z-index beneath parent step header |

### 3. Follow Mode

**Goal:** Auto-scroll to the bottom for running jobs. User can intentionally exit follow mode by scrolling up. A re-engagement bar appears when follow mode is off and the job is active.

| Interaction | Behaviour |
|-------------|-----------|
| Follow mode ON (default for active jobs) | Scrolls to bottom on every new item via `scrollTo({ top: scrollHeight, behavior: 'smooth' })` or `virtualizer.scrollToIndex(last, { align: 'end' })` |
| Auto-cancel threshold | 80px cumulative upward scroll (`CANCEL_THRESHOLD = 80`) cancels follow mode |
| Re-enable follow | Click "Follow latest" pill in `FollowModeBar` |
| FollowModeBar visibility | `sticky bottom-2 z-40`; visible only when `isActive=true` AND `autoFollow=false` |
| Job transitions to active | `useEffect` re-enables `autoFollow = true` on `isActive` flip |
| Job completes | Follow mode stays ON but becomes inert (no more new items); bar hides because `isActive=false` |
| Sidebar step click | Always cancels follow mode (`setAutoFollow(false)`) to prevent fighting with manual navigation |

## States and Variants Required

| State | Appearance |
|-------|------------|
| Hidden (`isActive=false` OR `autoFollow=true`) | `display: none` via `if (!visible) return null` |
| Visible (`isActive=true` AND `autoFollow=false`) | Pill CTA at sticky bottom-2; `bg-primary text-primary-foreground shadow-lg` |

| Active press | `active:scale-95` |

### BranchLifecycleBlock header trigger

| State | Appearance |
|-------|------------|
| Collapsed | Chevron at 0° rotation; compact single-row identity |
| Expanded | Chevron at 90° rotation; full header row visible |
| Hover | `hover:bg-accent/10` |
| Active (status=active) | Default open; semantic bg/border from `config.bgClass`/`config.borderClass` |
| Done (status=done) | Default collapsed; muted border |

### Step section in StepContentPane

| State | Appearance |
|-------|------------|
| Inactive | Standard sticky header — semantic bg + border |
| Active (running) | Left border accent: `border-l-[3px] border-l-sky-500` + animated pulse dot `bg-sky-400 animate-pulse` |
| With error | Error card below header: `text-rose-400 bg-rose-500/10 px-2 py-1 rounded` |
| New items | `animate-highlight-fade` for 1.5s on newly arrived items |
| Virtualized (>200 items) | No scroll-spy, no section IDs needed — virtual rows only |

## Accessibility Notes

- All interactive sticky headers must be keyboard-accessible via `CollapsibleTrigger` (Radix manages focus/aria)
- Follow mode bar `<button>` must have discernible accessible name: "Follow latest" text satisfies this
- Chevron rotation is CSS-only (`transition-transform`); no aria-expanded needed (Radix CollapsibleTrigger handles it)
- Depth-based visual hierarchy (pastel backgrounds) must not be the sole differentiator — border-l color provides secondary cue
- Sticky headers use `backdrop-blur` — ensure sufficient contrast against blurred content at all depths
