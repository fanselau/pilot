Create `src/core/smart-add.ts` — pure core module, no UI deps.

**`parseRequirementsFile(content: string): { itemCount: number; hasPhaseHeaders: boolean }`**
- Count lines matching `^\s*- \[ \]` regex (unchecked checkbox items)
- Detect phase headers: lines matching `^##\s+Phase\s+\d+` (case-insensitive)
- Also detect multiple `^###?\s+Must Have` sections (2+ = milestone indicator, treat like phase headers)
- Return `{ itemCount, hasPhaseHeaders }`

**`detectScope(opts: { content: string | null; description: string | null; isDirectory: boolean }): ScopeDetectionResult`**
- If `isDirectory` is true → milestone. Rationale: "Directory of requirements files detected".
- If `content` is provided:
  - Parse with `parseRequirementsFile(content)`
  - If `itemCount >= 10 && hasPhaseHeaders` → milestone. Rationale: "N requirement items with phase/section headers"
  - If `itemCount >= 3` → phase. Rationale: "N requirement items (focused feature)"
  - If `itemCount < 3` → quick. Rationale: "N items (small task)"
- If no content and description is provided:
  - → quick. Rationale: "String description (no requirements file)"
- If neither → quick with rationale: "No input provided, defaulting to quick"

**`generateRequirementsContent(description: string): string`**
- Title-case the first few words of description for `# Title` header
- Generate minimal valid requirements markdown:
  ```markdown
  # {Title}
  
  ## Problem
  {description}
  
  ## Requirements
  ### Must Have
  - [ ] {description}
  
  ## Do NOT
  - Break existing functionality
  ```
- Keep it minimal — GSD agents will work with this

**`detectProjectState(project: string, config: PilotConfig): Promise<ProjectStateResult>`**
- Check if `path.join(config.projectDir, project)` exists (fs.access)
- If not: return `{ exists: false, hasOpencode: false, hasPlanning: false, allPhasesDone: false, phasesIncomplete: false, isQueued: false, isRunning: false, queuedMode: null, runningPhase: null, needsSetup: false, needsInit: false }`
- Check `.opencode/` directory exists
- Check `.planning/` directory exists
- If .planning exists, use `detectPlanningState` from projects.ts to determine if all phases done or incomplete
- For isQueued/isRunning: import `getItems` from queue-store.ts. Filter items by project name. If any item has status 'running', set isRunning=true. If any has status 'queued', set isQueued=true. Extract queuedMode and runningPhase from matching items.
- Set `needsSetup = exists && !hasOpencode`
- Set `needsInit = exists && hasOpencode && !hasPlanning`

**`resolveInternalMode(scope: SmartAddScope, projectState: ProjectStateResult): string`**
- If `!projectState.exists` → 'build-full' (will error at command layer)
- If scope === 'quick' → 'quick'
- If scope === 'milestone':
  - If `!projectState.hasPlanning` → 'build-full'
  - If `projectState.allPhasesDone` → 'build-full' (new milestone)
  - If `projectState.phasesIncomplete` → 'continue-all' (finish current, then new work)
- If scope === 'phase':
  - If `!projectState.hasPlanning` → 'build-full' 
  - If `projectState.allPhasesDone` → 'add-and-build'
  - If `projectState.phasesIncomplete` → 'add-and-build'

Export all functions: `detectScope`, `detectProjectState`, `parseRequirementsFile`, `generateRequirementsContent`, `resolveInternalMode`.

Import only from: `node:fs/promises`, `node:path`, `./config.js`, `./types.js`, `./projects.js`, `./queue-store.js`. No UI deps.
