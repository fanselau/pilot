Replace with:

```typescript
if (this.activeJobs.size < this.options.maxParallel) {
  const job = getNextPending();
  if (job && !this.activeJobs.has(job.id)) {
    // Same-project serialization: skip if this project is already running in activeJobs
    const projectAlreadyActive = [...this.activeJobs.values()].some(
      ({ job: activeJob }) => activeJob.project === job.project,
    );
    if (projectAlreadyActive) {
      process.stderr.write(
        `[runner] Skipping ${job.id} (${job.project}): same-project job already active\n`,
      );
    } else {
      // Track BEFORE async launch so --once mode sees active jobs
      this.activeJobs.set(job.id, { job, title: '' });
      // Launch without awaiting — allows parallel jobs
      this.launch(job).catch(() => {
        // Error already handled in launch() via markFailed
      });
      continue; // Check for more immediately
    }
  }
}
```

Note: This check is against `this.activeJobs` (in-memory runner state), not the DB. The DB reconciliation (Task 2) handles the startup case where DB says running but runner restarted.

```typescript
const startupStale = reconcileStaleJobs(new Set(this.activeJobs.keys()));
if (startupStale.length > 0) {
  process.stderr.write(
    `[runner] Startup reconciliation: reset ${startupStale.length} stale-running job(s): ${startupStale.join(', ')}\n`,
  );
}
```

Then inside the main while loop, at the TOP of the loop body (before the capacity check), add periodic reconciliation:

```typescript
// Periodic reconciliation: reset ghost-running jobs every N cycles
this.pollCycle++;
if (this.pollCycle % Runner.RECONCILE_EVERY_N_CYCLES === 0) {
  const staleIds = reconcileStaleJobs(new Set(this.activeJobs.keys()));
  if (staleIds.length > 0) {
    process.stderr.write(
      `[runner] Periodic reconciliation: reset ${staleIds.length} stale-running job(s): ${staleIds.join(', ')}\n`,
    );
  }
}
```

The `reconcileStaleJobs` function compares DB's running jobs against `this.activeJobs`. Any job in DB as 'running' but NOT in `this.activeJobs` is stale — it's reset to 'pending' so it gets retried.
