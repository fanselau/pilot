  <files>src/commands/tail.ts, src/index.ts</files>
  <action>
    Update `src/commands/tail.ts` to support a `--smart` flag that adds log content analysis:

    1. Add `smart?: boolean` to the `TailOpts` interface.

    2. Import `analyzeLogContent`, `stripAnsi` from `../core/log-analyzer.js`.
    Import `yellow`, `red`, `bold` from `../util/colors.js`.

    3. When `--smart` is set, change the behavior of `readNewContent`:
       - After reading new content chunks, split into lines
       - Run each line through `analyzeLogContent([line])`
       - If a match is found, prefix the output line with a colored marker:
         - `question` category: yellow `⚠ WAITING: ` prefix
         - `work_done` category: yellow `⚠ DONE: ` prefix  
         - `inapplicable` category: red `⚠ N/A: ` prefix
       - Non-matching lines output normally (no prefix)

    4. When `--smart` is set, also do an initial scan of the last 50 lines of the existing log file BEFORE starting the follow:
       - Read the file, split by newlines, take last 50
       - Run through `analyzeLogContent`
       - If any matches found, print a banner BEFORE the "Following:" message:
         ```
         ⚠ Smart Analysis (last 50 lines)
         ─────────────────────────────────
           ⚠ N/A: "Verification not applicable for this project" (line 42)
           ⚠ DONE: "Phase 3 complete" (line 48)
         ```
       - If no matches, print: `✓ No stuck signals detected in last 50 lines`

    5. Update `src/index.ts` tail command registration:
       - Add `.option('-s, --smart', 'Analyze log for stuck signals')` to the tail command chain
       - The option gets passed through `mergeOpts` like all other flags

    Important: The normal (non-smart) tail behavior MUST remain unchanged. The --smart flag is purely additive. Do NOT change the file following logic, just add pre-analysis and line-level highlighting on top.

    Do NOT import React or Ink. This is a CLI command file.
