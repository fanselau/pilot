**Create web/src/components/timeline-fork-card.tsx:**

A visually distinct compact card for sub-agent fork points rendered inline in the timeline. Use Coss Card, Badge, Button components.

The card should display:
- Title / agent identity (session title)
- Status badge (active/done/unknown)
- Timing summary (duration, started-at time)
- Message count badge, token count badge
- Models used as small badges
- Latest message preview (line-clamped to 2 lines)
- "View details →" Link to `/jobs/$jobId/sessions/$sessionId`

Style it distinctly from regular activity items — use a left border accent color (e.g., `border-l-4 border-l-primary/40`) and slightly different background (`bg-muted/30`) to visually separate fork cards from regular activity.

Props: `{ item: TimelineForkCardItem; jobId: string }`

**Create web/src/components/timeline-stream.tsx:**

The main merged chronological timeline component. Accepts `jobId` and renders the merged timeline.

1. Use `useQuery` calling `getJobTimelineFn({ data: { jobId, limit: 100 } })` for initial load
2. Use `useJobDetailStream` for live updates on active jobs (invalidate timeline query on new events)
3. Render each TimelineItem by switching on `item.kind`:
   - `'activity'` → Render as a text activity row (time, role badge, text preview). Use Coss components: Badge for role, time displayed mono. Similar to existing ActivityPreview style but in the unified stream.
   - `'tool-summary'` → Render as a tool call row (time, tool badge, input preview, status badge). Expandable via Collapsible if toolInput is long.
   - `'fork-card'` → Render as `<TimelineForkCard item={item} jobId={jobId} />`
   - `'completion-card'` → Render as a subtle completion marker (Badge "done", duration, token count)
4. Use Coss ScrollArea for the timeline container
5. Support "Load more" at the bottom via cursor pagination (Button calling getJobTimelineFn with cursor)
6. Show empty state via Coss Empty component when no items

The timeline should use a subtle vertical line on the left (CSS pseudo-element or border) connecting items for visual continuity.

Props: `{ jobId: string; isActive: boolean }`
