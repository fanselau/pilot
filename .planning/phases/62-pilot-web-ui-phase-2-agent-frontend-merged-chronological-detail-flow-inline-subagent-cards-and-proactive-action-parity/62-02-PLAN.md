**Create web/src/lib/actions.ts** with the action registry:

```typescript
export interface ActionDefinition {
  id: string;
  label: string;
  description: string;
  group: 'job' | 'project' | 'navigation';
  /** Keyboard shortcut hint (display only, not bound here) */
  shortcut?: string;
  /** Returns true if action is available, or a string explaining why not */
  available: (ctx: ActionContext) => true | string;
  /** Execute the action. Returns void or a promise. */
  execute: (ctx: ActionContext) => void | Promise<void>;
}

export interface ActionContext {
  /** Currently selected/viewed job, if any */
  job?: { id: string; status: string; project: string; } | null;
  /** Currently selected/viewed project path, if any */
  projectPath?: string | null;
  /** Navigation function */
  navigate: (to: string) => void;
}

export interface ResolvedAction {
  definition: ActionDefinition;
  enabled: boolean;
  disabledReason: string | null;
}
```

Define the action registry array with these actions:
- `retry-job`: Available when job.status is 'failed'. Disabled reason: "Job is not in failed state". Calls retryJobFn.
- `cancel-job`: Available when job.status is 'running' or 'pending'. Disabled reason: "Job is not active". Calls cancelJobFn.
- `force-quit-job`: Available when job.status is 'running'. Disabled reason: "Job is not running". Calls forceQuitJobFn.
- `unblock-project`: Available when a project path is provided (always enabled in job context if project exists). Calls unblockProjectFn.
- `view-job-detail`: Available when job exists. Navigation action.
- `back-to-dashboard`: Always available. Navigation action.
- `refresh`: Always available. Calls queryClient.invalidateQueries.

Export `resolveActions(ctx: ActionContext): ResolvedAction[]` that evaluates each action's availability.

**Create web/src/lib/use-actions.ts** with the React hook:

```typescript
export function useActions(ctx: ActionContext): {
  actions: ResolvedAction[];
  enabledActions: ResolvedAction[];
  executeAction: (actionId: string) => Promise<void>;
}
```

The hook should:
1. Call resolveActions(ctx) to get all actions with availability status
2. Provide enabledActions filtered to only available ones
3. Provide executeAction helper that finds action by id and calls execute()
4. Use useQueryClient() internally so refresh action works
