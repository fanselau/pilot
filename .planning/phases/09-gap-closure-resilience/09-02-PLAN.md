    Add a new exported async function `detectGapClosureMisconfig` to `src/core/stuck.ts`:

    ```typescript
    interface GapClosureMisconfig {
      session: string;
      project: string;
      phase: number;
      summaryCount: number;
      originalPlanCount: number;
      detail: string;
    }

    async function detectGapClosureMisconfig(
      session: string,
      projectDir: string,
    ): Promise<GapClosureMisconfig | null>
    ```

    Logic:
    1. Parse session title to detect gap closure patterns:
       - Title contains `plan-phase` AND `--gaps` → gap planning session
       - Title contains `execute-phase` AND `--gaps-only` → gap execution session
       - If neither matches → return null (not a gap closure session)
    2. Extract phase number from the title (regex: `(?:plan-phase|execute-phase)\D*(\d+)`)
    3. Call `findPhaseDir(projectDir, phase)` to locate phase directory
    4. If no phase dir found → return null
    5. Call `countNonGapPlanFiles(phaseDir)` and `countSummaryFiles(phaseDir)`
    6. If summaryCount < originalPlanCount → return GapClosureMisconfig object with detail string:
       `"Gap closure on phase ${phase} but only ${summaryCount}/${originalPlanCount} original plans executed"`
    7. Otherwise return null

    Import `findPhaseDir`, `countSummaryFiles`, `countNonGapPlanFiles` from `./phase-state.js`.

    Export the `GapClosureMisconfig` interface and `detectGapClosureMisconfig` function.
  </action>
  <verify>`npm run lint` passes with no type errors</verify>
  <done>detectGapClosureMisconfig returns misconfig info for gap closure sessions on unexecuted phases, null otherwise</done>
