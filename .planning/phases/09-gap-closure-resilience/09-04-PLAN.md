
    Import `findPhaseDir`, `countSummaryFiles`, `countNonGapPlanFiles` from `./phase-state.js`.

    Logic:
    1. Parse session title to detect gap closure patterns:
       - Title contains `plan-phase` AND `--gaps` → gap planning session
       - Title contains `execute-phase` AND `--gaps-only` → gap execution session
       - If neither matches → return null (not a gap closure session)
    2. Extract phase number from the title using regex: `(?:plan-phase|execute-phase)\D*(\d+)`
       - If no phase number found → return null
    3. Extract project name from the title: everything before the first `-plan-phase` or `-execute-phase`
    4. Call `findPhaseDir(projectDir, phase)` to locate phase directory
       - If no phase dir found → return null
    5. Call `countNonGapPlanFiles(phaseDir)` and `countSummaryFiles(phaseDir)`
    6. If `summaryCount < originalPlanCount` → return GapClosureMisconfig object:
       ```typescript
       {
         session,
         project: extractedProject,
         phase,
         summaryCount,
         originalPlanCount,
         detail: `Gap closure on phase ${phase} but only ${summaryCount}/${originalPlanCount} original plans executed`,
       }
       ```
    7. Otherwise return null (execution evidence exists, gap closure is valid)

    Add `detectGapClosureMisconfig` and `GapClosureMisconfig` to the export block at the bottom of stuck.ts.
