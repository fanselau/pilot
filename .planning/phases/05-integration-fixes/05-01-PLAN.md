   The current code generates `{ permissions: { allow: ['**'] } }` which does NOT match what `validateConfig()` in `spawn.ts` expects. The correct format must have `permission` (singular) with sub-objects for each type:
   ```typescript

     permission: {

       write: { '**': 'allow' },
       edit: { '**': 'allow' },
       bash: { '**': 'allow' },
       external_directory: { '**': 'allow' },
     },
   };
   ```
   Change the filename from `claude.json` to `opencode.json`.
   Check for BOTH `opencode.json` AND `claude.json` existing — skip if either exists (to not overwrite legacy configs).

4. **Update .gitignore handling:**
   - Check for `.opencode/` in .gitignore (not `.claude/`)
   - Add `.opencode/` entry if missing
   - Also add `.opencode/` if only `.claude/` is present (don't remove `.claude/` — backward compat)

5. **Update module JSDoc comment** to reference `.opencode/` and `opencode.json` instead of `.claude/` and `claude.json`.
