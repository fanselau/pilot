  <name>Task 1: Fix --once mainLoop to wait for job completion</name>
  <files>src/core/runner.ts</files>
  <action>
Restructure `mainLoop()` (lines 131-189) to fix two problems: (1) dead code at line 173 (`this.opts.once && entry === null` can never fire — the else branch above handles null entries already), and (2) the bottom wait-for-all block is gated on `--once` when it should be unconditional to handle stragglers in any exit scenario.

**Exact changes to make:**

**A. In the else branch (entry === null), add `--once` early-break BEFORE the activeJobs check.** Insert this at line 164 (before `if (this.state.activeJobs.size > 0)`):
```typescript
      if (this.opts.once) {
        // --once: done scanning, break to wait-for-all block below
        break;
      }
```

**B. Remove dead code at lines 170-175.** Delete this block entirely:
```typescript
      // If --once flag and we just launched something, continue scanning
      // but don't loop after all entries have been processed
      if (this.opts.once && entry === null) {
        break;
      }
```

**C. Make the bottom wait-for-all block UNCONDITIONAL.** Replace lines 180-189:
```typescript
    // Before (only runs for --once):
    if (this.opts.once && !this.state.isShuttingDown) {
      while (this.state.activeJobs.size > 0) { ... }
    }
    
    // After (runs for any exit — safe because normal mode only breaks when activeJobs is empty):
    if (!this.state.isShuttingDown) {
      while (this.state.activeJobs.size > 0) {
        await this.reap();
        if (this.state.activeJobs.size > 0) {
          await sleep(2000);
        }
      }
    }
```

**Why this is safe for normal (non-once) mode:** The loop only breaks when `entry === null && activeJobs.size === 0`. So the bottom block's while condition is immediately false, and it's a no-op. No behavior change for normal mode.

**Why this fixes `--once`:** After launching all launchable entries, scan returns null → hits the new `--once` break → falls to unconditional wait-for-all → polls reap until all jobs complete → exits cleanly.
