The root cause is `sampleCpu(pid, 3, 10_000)` — 3 samples at 10s intervals = 30s per process. Two changes needed:

**Change 1: Add a `computeStuckScoreFast()` export** that skips CPU sampling entirely. This is what `pilot status` should use. It still computes all OTHER signals (log staleness, memory, proc state, wchan, runtime) which are instantaneous. Set `cpuSamples: []` in the scorer input — the scorer already handles empty arrays by defaulting maxCpu to 100 (assume active).

```typescript
/**
 * Fast stuck assessment — skips CPU sampling for use in status command.
 * Still evaluates: log staleness, memory, proc state, wchan, runtime.
 * CPU signal excluded (would take 30s per process).
 */
async function computeStuckScoreFast(pid: number, session: string): Promise<StuckAssessment> {
  const config = getConfig();
  const logFile = path.join(config.logDir, `gsd-${session}.log`);

  const [logStaleness, processRss, systemFreeMb, procState, wchan, runtime] =
    await Promise.all([
      getLogStaleness(logFile),
      getProcessRss(pid),
      getSystemFreeMem(),
      readProcState(pid),
      readProcWchan(pid),
      getProcessRuntime(pid),
    ]);

  const { score, verdict, signals } = scoreFromSignals({
    logStaleness,
    runtime,
    cpuSamples: [],  // Skip CPU — too slow for status dashboard
    messageCount: null,
    processRss,
    systemFreeMb,
    procState,
    wchan,
  });

  return {
    pid,
    session,
    score,
    verdict,
    signals,
    runtime_seconds: runtime,
    log_staleness_seconds: logStaleness,
  };
}
```

Add `computeStuckScoreFast` to the export list.

Keep the existing `computeStuckScore` unchanged — `pilot stuck` command still uses the full 30s CPU sampling for accurate scoring.

**Change 2: Add timeout to `sampleCpu()`.** Add an optional `timeoutMs` parameter (default: no timeout). If provided, abort sampling early when total elapsed time exceeds `timeoutMs`. Return whatever samples were collected. This protects `pilot stuck` from hanging indefinitely if there are many processes.

Modify the sampleCpu signature:
```typescript
async function sampleCpu(pid: number, count: number, intervalMs: number, timeoutMs?: number): Promise<number[]>
```

Inside the loop, check `if (timeoutMs !== undefined && Date.now() - loopStart > timeoutMs) break;` before each sleep.
