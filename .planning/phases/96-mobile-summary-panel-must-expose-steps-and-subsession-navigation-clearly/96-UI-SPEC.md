## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|

| sm | 8px | Compact element spacing, mobile touch row padding |
| md | 16px | Default element spacing |

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px (`text-xs`) | 400 (regular) | 1.4 |
| Heading | 16px (`text-base`) | 600 (semibold) | 1.25 |
| Display | 10px (`text-[10px]`) | 600 (semibold) | 1.2 |

Note: 2 weights only — regular (400) for body/labels, semibold (600) for headings/emphasis. "Display" here is used for micro-labels (step indices, duration stamps, section headers). This matches the existing mobile top-bar pattern (`text-[10px]`). Font-mono applied to step indices, durations, and code-like values.

## Mobile Step Navigation Drawer

### Interaction Contract

This phase adds a **bottom sheet step-navigation drawer** on mobile (viewport < 800px, detected by existing `useIsMobile()` hook). Currently, mobile users see only a compact top bar with status + "Summary" + "Info" buttons, but have **no way to see the step list or navigate between steps** — the `StepTimelineSidebar` is only rendered on desktop.

| Contract | Specification |
|----------|--------------|
| **Trigger** | "View steps" ghost button in mobile top bar, positioned between elapsed time and Summary button |
| **Surface** | Bottom sheet (`<Sheet>` with `side="bottom"`) — consistent with existing Summary/Info overlays |
| **Height** | 60vh default, swipe-dismissible (native Sheet behavior) |
| **Content** | Scrollable list of step groups, matching desktop sidebar step items in data density |
| **Step item height** | Minimum 44px (WCAG touch target) |
| **Step item layout** | Left: step index (mono) + semantic icon; Center: command label + status badge; Right: duration |
| **Active step** | `border-l-2 border-sky-400 bg-sky-500/5` highlight + "Live" info badge (matches desktop) |
| **Tap behavior** | Dismiss drawer → scroll content pane to tapped step via existing `scrollToStepRef` |
| **Subsession indicator** | Steps containing subsessions show a small "fork" icon (existing `TimelineForkCard` pattern) with count badge |
| **Keyboard nav** | Not required on mobile (touch-primary surface) |

### Step Item Visual Spec

```
┌─────────────────────────────────────────────┐
│ ⓘ  #3  delegation        completed   12s   │
│       └─ Session 1 (claude-sonnet)          │
│ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ │
│ ⓘ  #4  judge             running    Live    │
│ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ │
│ ⓘ  #5  delegation        pending     —     │
│       └─ Session 2 (gpt-5.4)               │
└─────────────────────────────────────────────┘
```

- Step index: `text-xs font-mono tabular-nums text-muted-foreground` (w-5)
- Semantic icon: `h-3 w-3 shrink-0 text-muted-foreground` (from `SEMANTIC_TYPE_CONFIG`)
- Command label: `text-xs font-mono leading-tight truncate`
- Status badge: `<Badge variant={stepStatusVariant} size="sm">`
- Duration: `text-[10px] font-mono text-muted-foreground tabular-nums`
- Subsession line: `text-[10px] text-muted-foreground ml-7` with fork icon `h-2.5 w-2.5`

## Subsession Navigation Within Steps

### Current Behavior

On mobile, subsession content renders inline within the continuous scroll (`StepContentPane`). Subsession fork cards (`TimelineForkCard`) are visible but there's no way to jump to specific subsessions within a step.

### New Behavior

| Contract | Specification |
|----------|--------------|
| **Subsession chips** | When a step has subsessions, render a row of small tappable chips below the step header in the content pane |
| **Chip layout** | Horizontal scroll row, `flex gap-1.5 overflow-x-auto py-1 px-3` |
| **Chip design** | `<Badge variant="outline" size="sm" className="shrink-0 text-[10px]">` |
| **Chip label** | `S1`, `S2`, etc. (compact) + model short name if available: `S1 · sonnet` |
| **Chip tap** | Scroll to the subsession's fork card element within the current step using `scrollIntoView({ behavior: 'smooth', block: 'start' })` |
| **Active chip** | If subsession is currently running: `variant="info"` + pulse dot |
| **Visibility** | Only shown on mobile (`isMobile`) and only for steps with ≥ 1 subsession |
