1. **src/core/config.ts** — Implement `getConfig(): PilotConfig`:
   - Resolve each env var with defaults using `process.env`:
     - `PILOT_QUEUE_FILE` → default `${os.homedir()}/dev/punchlab/QUEUE.md`
     - `PILOT_LOG_DIR` → default `/tmp`
     - `PILOT_STUCK_THRESHOLD` → default `90` (parse as number)
     - `PILOT_PROJECT_DIR` → default `${os.homedir()}/dev/punchlab`
     - `PILOT_GSD_DIR` → default `${os.homedir()}/dev/punchlab/pilot-gsd`
     - `NO_COLOR` → `true` if env var is set (any value), `false` if unset
   - Expand `~` to `os.homedir()` in path values (in case user sets `PILOT_QUEUE_FILE=~/custom/QUEUE.md`)
   - Import `PilotConfig` from `./types.js` (note .js extension for ESM)
   - Named export only: `export { getConfig }`

2. **src/util/format.ts** — Pure formatting helpers:
   - `formatDuration(seconds: number): string` — Returns human-friendly duration:
     - `< 60` → `"30s"`
     - `60-3599` → `"45m"` or `"1h 30m"`
     - `≥ 3600` → `"2h 15m"`
     - `0` → `"0s"`
   - `truncateString(str: string, maxLen: number): string` — Truncates with `"…"` if too long
   - `truncateTitle(str: string, maxLen?: number): string` — Default maxLen 80, for session titles
   - `formatProgressBar(percent: number, width?: number): string` — Default width 10. Uses `"█"` for filled, `"░"` for empty. E.g., 60% width 10 → `"██████░░░░"`
   - All named exports. ZERO dependencies (pure functions).

3. **src/util/colors.ts** — picocolors wrapper:
   - Import `picocolors` (the `pc` default import pattern)
   - Check `process.env.NO_COLOR` — if set, export identity functions
   - Export named functions: `dim`, `bold`, `green`, `red`, `yellow`, `cyan`, `blue`, `magenta`, `gray`
   - Each function: `(str: string) => string`

4. **src/util/output.ts** — JSON/human output helpers:
   - Track json mode via a module-level variable, set by `setJsonMode(enabled: boolean)`
   - `isJsonMode(): boolean`
   - `outputJson(data: Record<string, unknown>): void` — Adds `timestamp` (ISO 8601 UTC) to data, writes to `process.stdout.write(JSON.stringify({timestamp, ...data}, null, 2) + '\n')`. Do NOT use `console.log`.
   - `outputHuman(text: string): void` — `process.stdout.write(text + '\n')` only if NOT json mode
   - Named exports only.

5. **test/core/config.test.ts** — Tests:
   - Test default values when no env vars set (mock process.env)
   - Test each env var override
   - Test `~` expansion in custom paths
   - Test `NO_COLOR` detection (set vs unset)
   - Test `PILOT_STUCK_THRESHOLD` parses as number

Also add inline tests or a test file for format.ts covering: formatDuration edge cases (0, 30, 60, 90, 3600, 8100), truncateString (short string unchanged, long string truncated with …), formatProgressBar (0%, 50%, 100%).

Run `npm test` to verify all tests pass.
