1. **src/core/projects.ts** — Implement:

   - **scanProjects(): Promise&lt;ProjectInfo[]&gt;**
     - Read `getConfig().projectDir` directory entries with `readdir({ withFileTypes: true })`
     - Filter to directories only
     - For each: call `getProjectInfo(path)`
     - Sort by name alphabetically
     - Skip hidden directories (starting with `.`)

   - **getProjectInfo(projectPath: string): Promise&lt;ProjectInfo&gt;**
     - `name`: directory basename
     - `path`: absolute path
     - `branch`: run `execa('git', ['branch', '--show-current'], { cwd: projectPath })` → stdout.trim(). On error: `"unknown"`
     - `gitState`: run `execa('git', ['status', '--porcelain'], { cwd: projectPath })` → if stdout is empty: `"clean"`, else `"dirty"`. On error: `"clean"` (not a git repo)
     - `planningState`: call `detectPlanningState(path.join(projectPath, '.planning'))`
     - `currentPhase` and `currentPhaseState`: from detectPlanningState
     - `progress`: from counting phases in ROADMAP.md

   - **detectPlanningState(planningDir: string): Promise&lt;{state: 'no-planning' | 'active' | 'completed'; currentPhase?: number; currentPhaseState?: string; progress: {done: number; total: number; percent: number}}&gt;**
     - If `.planning/` doesn't exist → `{ state: 'no-planning', progress: { done: 0, total: 0, percent: 0 } }`
     - Read `.planning/ROADMAP.md` — count `### Phase N:` lines for total
     - Read `.planning/STATE.md` — extract `Current Phase: N`
     - Scan `.planning/phases/` directories, check for SUMMARY.md files (completed) or PLAN.md files (planned)
     - Count done phases (have SUMMARY.md for all plans)
     - Calculate percent: `Math.round((done / total) * 100)` or 0 if total is 0
     - If all done → state = 'completed'
     - Otherwise → state = 'active', currentPhase from STATE.md
     - For currentPhaseState: check phase directory for PLAN.md (planned), SUMMARY.md (executing/done), UAT.md (verifying)

   Use `node:fs/promises` for all file ops. Use `execa` for git commands (not child_process). Handle all errors gracefully — missing files return defaults, not crashes.

2. **src/core/progress.ts** — Implement:

   - **getProgress(projectPath: string): Promise&lt;ProgressInfo&gt;**
     - Read `.planning/ROADMAP.md` — parse phases: `### Phase N: Name`
     - For each phase: check `.planning/phases/{padded}-*/`:
       - Count PLAN.md files (total plans)
       - Count SUMMARY.md files (done plans)
       - Determine status: all summaries = 'done', some = 'executing', plans exist but no summaries = 'planning', no dir = 'pending'
     - Read `.planning/STATE.md` for current phase
     - Determine nextAction: based on current phase state ('plan phase N', 'execute phase N', 'verify phase N')
     - Blockers: empty array for now (Phase 2 may add stuck detection here)
     - Return ProgressInfo

   - Test getProjectInfo with mocked git commands
   - Test getProgress with mock ROADMAP.md and phase directories
   - Mock execa for git commands, use real filesystem (temp dirs) for .planning state

Clean up temp dirs after tests.

Create `src/core/setup.ts` with:

**setupProject(dir: string): Promise&lt;SetupResult&gt;**

Where SetupResult is:
```typescript
interface SetupResult {
  created: string[];    // list of things created
  skipped: string[];    // list of things skipped (already exist)
  errors: string[];     // list of errors
}
```

Steps (matching spec §4 `pilot setup`):

1. **Resolve dir** to absolute path using `path.resolve()`

2. **Create dir** if it doesn't exist: `mkdir(dir, { recursive: true })`

3. **Create .claude/ directory** (note: the spec says `.Claude/` but per the opencode.json convention, use `.claude/`): `mkdir(path.join(dir, '.claude'), { recursive: true })`

4. **Create symlinks** (all relative to .claude/):
   - `.claude/command/` → `${config.gsdDir}/commands/` (note: target is `commands/` plural in spec)
   - `.claude/agents/` → `${config.gsdDir}/agents/`
   - `.claude/get-shit-done/` → `${config.gsdDir}/get-shit-done/`
   
   For each symlink:
   - Check if target directory exists first. If not → add error, skip.
   - Check if symlink already exists. If so → add to skipped, skip.
   - Create with `fs.symlink(target, linkPath)` (absolute paths for targets)

5. **Create claude.json** (the spec says `Claude.json` — use lowercase `claude.json` to match modern conventions):
   - If file already exists → skip, add note to skipped
   - If not: write the permissive config from spec:
   ```json
   {
     "permissions": {
       "allow": ["**"]
     }
   }
   ```
   (Note: the exact schema depends on the Claude/opencode config format. The spec gives a specific JSON structure — use EXACTLY what the spec says in §4 under `pilot setup`)

6. **Update .gitignore** — If `.gitignore` exists, check if `.claude/` is already in it. If not, append `.claude/` on a new line. If `.gitignore` doesn't exist, create it with `.claude/\n`.

7. **Git init** — If dir is not already a git repo (check for `.git/` directory), run `execa('git', ['init', '-q'], { cwd: dir })`.

Return the SetupResult with lists of what was created, skipped, and any errors.

Import `getConfig` from `./config.js`.

**Important:** Do NOT overwrite existing claude.json (spec explicitly says skip with note). Do NOT use hard copies — always symlink.
