  <name>Task 1: Process management module</name>
  <files>
    src/core/process.ts
  </files>
  <action>
Create `src/core/process.ts` with the following exports (all named, no defaults):

1. **readPidFile(session: string): Promise&lt;number | null&gt;**
   - Read `${config.logDir}/gsd-${session}-pid` (keep `gsd-` prefix for backward compat per spec)
   - Parse content as integer
   - Return null if file doesn't exist or content isn't a valid number
   - Use `node:fs/promises` readFile with try/catch for ENOENT

2. **writePidFile(session: string, pid: number): Promise&lt;void&gt;**
   - Write pid as string to `${config.logDir}/gsd-${session}-pid`

3. **removePidFile(session: string): Promise&lt;void&gt;**
   - Delete `${config.logDir}/gsd-${session}-pid`
   - Ignore ENOENT (file already gone)

4. **scanPidFiles(): Promise&lt;Array&lt;{session: string; pid: number}&gt;&gt;**
   - Glob `${config.logDir}/gsd-*-pid` using `node:fs/promises` readdir + filter
   - For each file: extract session name from filename pattern `gsd-${session}-pid`
   - Read PID from file, verify process is alive with `isProcessAlive`
   - Return only entries with alive PIDs

5. **isProcessAlive(pid: number): boolean**
   - Use `process.kill(pid, 0)` in try/catch
   - Returns true if no error, false if ESRCH
   - EPERM (permission denied) → return true (process exists, just can't signal)

6. **getProcessRuntime(pid: number): number | null**
   - Read `/proc/${pid}/stat` — field 22 (0-indexed: 21) is starttime in clock ticks
   - Read `/proc/uptime` for system uptime in seconds
   - Calculate: `runtime = system_uptime - (starttime / CLK_TCK)`
   - `CLK_TCK` = 100 on Linux (standard)
   - Return seconds as number, null if /proc files unreadable

Import `getConfig` from `./config.js`. Import types as needed from `./types.js`.

Do NOT use `child_process`. Do NOT use `fs.existsSync` (use async fs.access or try/catch on read).
  </action>

`npm run build` compiles. Manual review: all functions use async fs, no sync operations in hot paths, no `any` types.
  </verify>
  <done>
process.ts exports all 6 functions. PID files use `gsd-` prefix. getProcessRuntime reads /proc correctly. isProcessAlive handles ESRCH and EPERM.
  </done>
