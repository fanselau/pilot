    In `executeCommandStep` (around line 937), after `spawnAndWait` returns successfully and before `dbMarkStepCompleted`, add checkpoint pause detection:

    1. After spawnAndWait returns, get the session's state by calling `findSessionByTitle(title)` to get sessionId
    2. Check if the session ended because it hit a GSD checkpoint. Detection heuristic:
       - Call `getAssistantMessageCount(sessionId)` — if > 0, check the last assistant message content for checkpoint indicators
       - Import and use a new helper `detectCheckpointPause(sessionId: string): { isCheckpoint: boolean; reason: string }` 
       - The helper queries the opencode DB's `part` table for the last assistant message containing "CHECKPOINT" (case-insensitive) in its content, or checks if the session's last tool call was a `question` type tool that was resolved (not hung)
    3. If checkpoint detected AND there are remaining pending steps (`getPendingStepCount(job.id) > 0`):
       - Call `dbMarkStepCompleted(step.id, sessionId ?? undefined, title)` to complete the current step
       - Call `markReviewHold(job.id, reason)` where reason is "Checkpoint paused after step: {step.command} {step.args}. Remaining steps: {pendingCount}"
       - Call `notifyJobCompletion(getJob(job.id)!)` for notification
       - Return early (don't continue step loop)
    4. If no checkpoint OR no remaining steps: proceed normally (mark completed, continue loop)

    The `detectCheckpointPause` function should be an exported module-level function (same pattern as `isHumanOnlyRemaining`) for testability:

    ```typescript
    export function detectCheckpointPause(sessionId: string | null): { isCheckpoint: boolean; reason: string } {
      if (!sessionId) return { isCheckpoint: false, reason: '' };
      // Query last few assistant messages for checkpoint indicators
      // Look for "CHECKPOINT" in content (GSD executors output "## CHECKPOINT REACHED" or similar)
      // Look for resolved question tool calls (user was prompted)
      const db = openDb();
      if (!db) return { isCheckpoint: false, reason: '' };
      
      // Check last N parts for checkpoint content
      const checkpointPart = db.prepare(`
        SELECT json_extract(data, '$.content') as content
        FROM part
        WHERE session_id = ?
          AND json_extract(data, '$.type') = 'text'
          AND json_extract(data, '$.role') = 'assistant'
          AND UPPER(json_extract(data, '$.content')) LIKE '%CHECKPOINT%'
        ORDER BY time_created DESC LIMIT 1
      `).get(sessionId) as { content: string } | undefined;
      
      if (checkpointPart) {
        return { isCheckpoint: true, reason: checkpointPart.content.slice(0, 200) };
      }
      return { isCheckpoint: false, reason: '' };
    }
    ```

    Import `openDb` from `./opencode-db.js` (already imported elsewhere in runner.ts for `findSessionByTitle`, `getSessionState`, etc.).
