    **In src/commands/skills.ts:**

    1. Add import at top: `import { bootstrapDefaultSkills, recommendDefaultSkills } from '../core/default-skills.js';`

    2. Add new `skillsSeedCommand` function that:
       - Accepts `options: { yes?: boolean; projectDir?: string }` (projectDir defaults to `process.cwd()`)
       - Calls `recommendDefaultSkills(projectDir, { tier: 'all' })` to preview what will be registered
       - Outputs a preview: skill count, tier 1 count, tier 2 count, detected stack
       - Calls `bootstrapDefaultSkills({ projectDir, yes: true, tier: 'all' })` to register all
       - Outputs result: `✓ Seeded N skills (M tier-1, K tier-2). N failed.`
       - If errors, output each error line
       - Note: `bootstrapDefaultSkills` uses `registerSkill()` which overwrites existing entries by name — this naturally replaces stale old-format entries

    3. Export `skillsSeedCommand` from the exports block at bottom

    **In src/index.ts (after the `tag` subcommand block, around line 335):**

    4. Add `seed` subcommand to `skillsCmd`:
       ```
       skillsCmd
         .command('seed')
         .description('Populate manifest from built-in skill catalog (Tier 1 + detected Tier 2)')
         .option('--yes', 'Skip confirmation')
         .option('--project-dir <dir>', 'Project directory for stack detection', process.cwd())
         .action(async (opts: Record<string, unknown>) => {
           const { skillsSeedCommand } = await import('./commands/skills.js');
           await skillsSeedCommand(opts as { yes?: boolean; projectDir?: string });
         });
       ```

    **Important:** The `--project-dir` flag is needed because `detectProjectStack()` reads the project's package.json/tsconfig/wrangler to detect Tier 2 stack skills. Default to cwd.
