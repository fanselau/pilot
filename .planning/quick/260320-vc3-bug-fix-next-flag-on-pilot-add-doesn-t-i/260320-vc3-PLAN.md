<objective>
Fix bug: `--next` flag on `pilot add` doesn't insert at front of queue.

Purpose: The `--next` flag is accepted by the CLI and passed to `addCommand()` via `AddOptions.next`, but the flag is never acted upon — the job is always created with default priority 0. The fix is to call `bump(job.id)` after `addJob()` when `opts.next` is true, reusing the same mechanism that makes `pilot bump` work correctly.

Output: Working `--next` flag with test coverage.
</objective>
